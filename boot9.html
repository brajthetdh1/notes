Spring Cloud Gateway: Complete Guide

Introduction to Spring Cloud Gateway

Spring Cloud Gateway is a powerful API Gateway built on Spring Framework 5, Project Reactor, and Spring Boot 2. It provides a simple yet effective way to route to APIs and provide cross-cutting concerns such as security, monitoring, metrics, and resilience for microservices architectures.

Unlike traditional proxy servers, Spring Cloud Gateway uses a non-blocking API and supports WebSocket connections, making it ideal for modern reactive applications. It acts as a single entry point for all client requests, routing them to appropriate backend services while handling common concerns like authentication, rate limiting, and circuit breaking.

Key Features: Spring Cloud Gateway offers dynamic routing, path rewriting, circuit breaker integration, rate limiting, JWT authentication, header manipulation, and built-in resilience patterns through integration with Spring Cloud CircuitBreaker.

Core Concepts and Architecture

Spring Cloud Gateway Architecture

Route
URI + Predicates + Filters
Predicate
Request Matching Conditions
Filter
Request/Response Modification
WebHandler
Request Processing Pipeline

Route: The basic building block of the gateway. It consists of an ID, a destination URI, a collection of predicates, and a collection of filters. A route is matched when all its predicates evaluate to true.

Predicate: Java 8 Function Predicate that determines if a request matches a route. Spring Cloud Gateway includes many built-in predicate factories for matching based on path, header, method, host, and more.

Filter: GatewayFilter instances that can modify requests and responses before or after sending the downstream request. Filters can perform tasks like adding headers, path rewriting, circuit breaking, and rate limiting.

            .route("product_service", r -> r
                .path("/api/products/**")
                .filters(f -> f
                    .stripPrefix(2)
                    .requestRateLimiter(config -> config
                        .setRateLimiter(redisRateLimiter())
                        .setKeyResolver(userKeyResolver()))
                    .rewritePath("/api/products/(?<segment>.*)", "/$\{segment}"))
                .uri("lb://product-service"))
            
            // Route with JWT authentication
            .route("secure_service", r -> r
                .path("/api/secure/**")
                .filters(f -> f
                    .stripPrefix(2)
                    .filter(authenticationFilter())
                    .modifyResponseBody(String.class, String.class, 
                        (exchange, s) -> Mono.just(s.toUpperCase())))
                .uri("lb://secure-service"))
            
            // Route with custom predicate
            .route("custom_route", r -> r
                .asyncPredicate(serverWebExchange -> {
                    // Custom predicate logic
                    return Mono.just(true);
                })
                .uri("lb://custom-service"))
            
            .build();
    }
    
    @Bean
    public RedisRateLimiter redisRateLimiter() {
        return new RedisRateLimiter(10, 20);
    }

    KeyResolver userKeyResolver() {
        return exchange -> Mono.just(
            exchange.getRequest().getRemoteAddress().getAddress().getHostAddress());

Global Filter Configuration


@Configuration
public class GlobalFilterConfiguration {
    
    // Global filters apply to all routes
    @Bean
    @Order(-1)
    public GlobalFilter loggingFilter() {
        return (exchange, chain) -> {
            ServerHttpRequest request = exchange.getRequest();
            String path = request.getPath().value();
            String method = request.getMethod().name();
            
            log.info("Incoming request: {} {}", method, path);
            
            return chain.filter(exchange).then(Mono.fromRunnable(() -> {
                ServerHttpResponse response = exchange.getResponse();
                log.info("Response status: {} for {} {}", 
                    response.getStatusCode(), method, path);
            }));
        };
    }
    
    @Bean
    @Order(0)
    public GlobalFilter authenticationFilter() {
        return (exchange, chain) -> {
            ServerHttpRequest request = exchange.getRequest();
            String authHeader = request.getHeaders().getFirst("Authorization");
            
            if (authHeader != null && authHeader.startsWith("Bearer ")) {
                // Validate JWT token
                String token = authHeader.substring(7);
                if (validateToken(token)) {
                    // Add user info to headers
                    ServerHttpRequest modifiedRequest = request.mutate()
                        .header("X-User-ID", extractUserId(token))
                        .header("X-User-Roles", extractUserRoles(token))
                        .build();
                    
                    return chain.filter(exchange.mutate().request(modifiedRequest).build());
                }
            }
            
            // For protected routes, return 401
            if (isProtectedRoute(request.getPath().value())) {
                exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
                return exchange.getResponse().setComplete();
            }
            
            return chain.filter(exchange);
        };
    }
    
    @Bean
    @Order(1)
    public GlobalFilter rateLimitingFilter() {
        return new RateLimitingFilter();
    }
    
    @Bean
    @Order(2)
    public GlobalFilter corsFilter() {
        return (exchange, chain) -> {
            ServerHttpResponse response = exchange.getResponse();
            HttpHeaders headers = response.getHeaders();
            
            headers.add("Access-Control-Allow-Origin", "*");
            headers.add("Access-Control-Allow-Methods", "GET, PUT, POST, DELETE, OPTIONS");
            headers.add("Access-Control-Allow-Headers", "Content-Type, Authorization");
            
            if (exchange.getRequest().getMethod() == HttpMethod.OPTIONS) {
                response.setStatusCode(HttpStatus.OK);
                return Mono.empty();
            }
            
            return chain.filter(exchange);
        };
    }
}

Custom Gateway Filters


@Component
public class CustomAuthFilter implements GatewayFilter {
    
    private final JwtService jwtService;
    
    public CustomAuthFilter(JwtService jwtService) {
        this.jwtService = jwtService;
    }
    
    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        ServerHttpRequest request = exchange.getRequest();
        String path = request.getPath().value();
        
        // Skip auth for public endpoints
        if (isPublicEndpoint(path)) {
            return chain.filter(exchange);
        }
        
        // Extract and validate JWT
        String token = extractToken(request);
        if (token == null || !jwtService.validateToken(token)) {
            exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
            return exchange.getResponse().setComplete();
        }
        
        // Add user context to request
        UserContext userContext = jwtService.extractUserContext(token);
        ServerHttpRequest modifiedRequest = request.mutate()
            .header("X-User-ID", userContext.getUserId())
            .header("X-User-Roles", String.join(",", userContext.getRoles()))
            .build();
        
        return chain.filter(exchange.mutate().request(modifiedRequest).build());
    }
    
    private String extractToken(ServerHttpRequest request) {
        String authHeader = request.getHeaders().getFirst("Authorization");
        if (authHeader != null && authHeader.startsWith("Bearer ")) {
            return authHeader.substring(7);
        }
        return null;
    }
    
    private boolean isPublicEndpoint(String path) {
        return path.startsWith("/api/public/") || 
               path.equals("/api/health") || 
               path.startsWith("/actuator/");
    }
}

@Configuration
@EnableWebFluxSecurity
public class SecurityConfig {
    
    @Bean
    public SecurityWebFilterChain springSecurityFilterChain(ServerHttpSecurity http) {
        return http
            .csrf().disable()
            .authorizeExchange(exchanges -> exchanges
                // Public endpoints
                .pathMatchers("/api/public/**", "/api/health", "/actuator/**").permitAll()
                // Role-based access
                .pathMatchers("/api/admin/**").hasRole("ADMIN")
                .pathMatchers("/api/user/**").hasAnyRole("USER", "ADMIN")
                .pathMatchers("/api/secure/**").authenticated()
                // All other requests require authentication
                .anyExchange().authenticated())
            .oauth2ResourceServer(oauth2 -> oauth2
                .jwt(jwt -> jwt
                    .jwtAuthenticationConverter(jwtAuthenticationConverter())))
            .build();
    }
    
    private Converter<Jwt, ? extends Mono<? extends AbstractAuthenticationToken>> 
            jwtAuthenticationConverter() {
        
        JwtAuthenticationConverter converter = new JwtAuthenticationConverter();
        converter.setJwtGrantedAuthoritiesConverter(jwt -> {
            // Extract roles from JWT
            List<String> roles = jwt.getClaimAsStringList("roles");
            if (roles == null) {
                return Collections.emptyList();
            }
            return roles.stream()
                .map(role -> new SimpleGrantedAuthority("ROLE_" + role))
                .collect(Collectors.toList());
        });
        
        return new ReactiveJwtAuthenticationConverterAdapter(converter);
    }
}

// JWT Service for token validation
@Service
public class JwtService {
    
    private final SecretKey secretKey;
    
    public JwtService(@Value("${jwt.secret}") String secret) {
        this.secretKey = Keys.hmacShaKeyFor(secret.getBytes());
    }
    
    public boolean validateToken(String token) {
        try {
            Jwts.parserBuilder()
                .setSigningKey(secretKey)
                .build()
                .parseClaimsJws(token);
            return true;
        } catch (JwtException e) {
            return false;
        }
    }
    
    public UserContext extractUserContext(String token) {
        Claims claims = Jwts.parserBuilder()
            .setSigningKey(secretKey)
            .build()
            .parseClaimsJws(token)
            .getBody();
        
        String userId = claims.getSubject();
        List<String> roles = claims.get("roles", List.class);
        
        return new UserContext(userId, roles != null ? roles : List.of());
    }
}

@Component
public class GatewayHealthIndicator implements HealthIndicator {
    
    private final GatewayMetrics gatewayMetrics;
    
    public GatewayHealthIndicator(GatewayMetrics gatewayMetrics) {
        this.gatewayMetrics = gatewayMetrics;
    }
    
    @Override
    public Health health() {
        // Check if gateway is healthy based on metrics
        long errorCount = gatewayMetrics.getErrorCount();
        double errorRate = gatewayMetrics.getErrorRate();
        
        Health.Builder status = errorRate > 0.1 ? 
            Health.down() : Health.up();
        
        return status
            .withDetail("totalRequests", gatewayMetrics.getTotalRequests())
            .withDetail("errorCount", errorCount)
            .withDetail("errorRate", errorRate)
            .withDetail("averageResponseTime", gatewayMetrics.getAverageResponseTime())
            .build();
    }
}

@Component
public class GatewayMetrics {
    
    private final MeterRegistry meterRegistry;
    private final Counter requestCounter;
    private final Counter errorCounter;
    private final Timer responseTimer;
    
    public GatewayMetrics(MeterRegistry meterRegistry) {
        this.meterRegistry = meterRegistry;
        this.requestCounter = Counter.builder("gateway.requests")
            .description("Total gateway requests")
            .register(meterRegistry);
        this.errorCounter = Counter.builder("gateway.errors")
            .description("Total gateway errors")
            .register(meterRegistry);
        this.responseTimer = Timer.builder("gateway.response.time")
            .description("Gateway response time")
            .register(meterRegistry);
    }
    
    public void recordRequest(String path, String method, long duration, boolean error) {
        requestCounter.increment();
        responseTimer.record(duration, TimeUnit.MILLISECONDS);
        
        if (error) {
            errorCounter.increment();
        }
        
        // Record with tags
        meterRegistry.counter("gateway.requests.detailed",
            "path", path,
            "method", method,
            "status", error ? "error" : "success")
            .increment();
    }
}

Spring Cloud Gateway: Complete Guide

Introduction to Spring Cloud Gateway

Spring Cloud Gateway is a powerful API Gateway built on Spring Framework 5, Spring Boot 2, and Project Reactor. It provides a simple, yet effective way to route to APIs and provide cross-cutting concerns such as security, monitoring/metrics, and resilience. As the entry point for all client requests, it acts as a reverse proxy, routing requests to appropriate backend services while applying various filters and policies.

Core Architecture: Spring Cloud Gateway uses a non-blocking, reactive programming model built on Project Reactor, making it highly scalable and efficient for handling high-throughput API traffic. It operates on the concept of routes, predicates, and filters to provide flexible request routing and processing.

Routes

The basic building block containing ID, destination URI, predicates, and filters

@Component
public class AuthenticationFilter implements GlobalFilter {
    
    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        ServerHttpRequest request = exchange.getRequest();
        String path = request.getPath().value();
        
        // Skip auth for public endpoints
        if (path.startsWith("/public/") || path.equals("/health")) {
            return chain.filter(exchange);
        }
        
        // Check for authentication token
        String authHeader = request.getHeaders().getFirst("Authorization");
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            return onError(exchange, "Missing authorization token", 
                HttpStatus.UNAUTHORIZED);
        }
        
        // Validate token (simplified)
        String token = authHeader.substring(7);
        if (!isValidToken(token)) {
            return onError(exchange, "Invalid token", HttpStatus.UNAUTHORIZED);
        }
        
        // Add user info to request headers
        ServerHttpRequest modifiedRequest = request.mutate()
            .header("X-User-ID", extractUserId(token))
            .header("X-User-Roles", extractUserRoles(token))
            .build();
            
        return chain.filter(exchange.mutate().request(modifiedRequest).build());
    }
    
    private Mono<Void> onError(ServerWebExchange exchange, String err, HttpStatus status) {
        ServerHttpResponse response = exchange.getResponse();
        response.setStatusCode(status);
        return response.setComplete();
    }
    
    private boolean isValidToken(String token) {
        // Implement token validation logic
        return token != null && !token.isEmpty();
    }
    
    private String extractUserId(String token) {
        // Extract user ID from token
        return "user123";
    }
    
    private String extractUserRoles(String token) {
        // Extract roles from token
        return "ROLE_USER,ROLE_READER";
    }
}

@Component
public class RateLimitingFilter implements GatewayFilterFactory<RateLimitingFilter.Config> {
    
    private final RedisRateLimiter redisRateLimiter;
    
    public RateLimitingFilter(RedisRateLimiter redisRateLimiter) {
        this.redisRateLimiter = redisRateLimiter;
    }
    
    @Override
    public GatewayFilter apply(Config config) {
        return (exchange, chain) -> {
            ServerHttpRequest request = exchange.getRequest();
            String apiKey = request.getHeaders().getFirst("X-API-Key");
            
            if (apiKey == null) {
                return onError(exchange, "Missing API Key", HttpStatus.BAD_REQUEST);
            }
            
            return redisRateLimiter.isAllowed(apiKey, config.getRequestsPerMinute())
                .flatMap(response -> {
                    if (response.isAllowed()) {
                        exchange.getResponse().getHeaders()
                            .add("X-RateLimit-Remaining", 
                                String.valueOf(response.getRemainingTokens()));
                        return chain.filter(exchange);
                    } else {
                        return onError(exchange, "Rate limit exceeded", 
                            HttpStatus.TOO_MANY_REQUESTS);
                    }
                });
        };
    }
    
    @Override
    public Class<Config> getConfigClass() {
        return Config.class;
    }
    
    @Override
    public List<String> shortcutFieldOrder() {
        return Arrays.asList("requestsPerMinute");
    }
    
    public static class Config {
        private int requestsPerMinute = 60;
        
        public int getRequestsPerMinute() { return requestsPerMinute; }

    }
    
    private Converter<Jwt, ? extends Mono<? extends AbstractAuthenticationToken>> 
            jwtAuthenticationConverter() {
        
        JwtAuthenticationConverter converter = new JwtAuthenticationConverter();
        converter.setJwtGrantedAuthoritiesConverter(jwt -> {
            List<String> roles = jwt.getClaimAsStringList("roles");
            if (roles == null) {
                return Collections.emptyList();
            }
            return roles.stream()
                .map(role -> new SimpleGrantedAuthority("ROLE_" + role))
                .collect(Collectors.toList());
        });
        
        return converter;
    }
}

@Component
public class JwtValidationFilter implements GlobalFilter {
    
    private final JwtDecoder jwtDecoder;
    
    public JwtValidationFilter(JwtDecoder jwtDecoder) {
        this.jwtDecoder = jwtDecoder;
    }
    
    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        String authHeader = exchange.getRequest()
            .getHeaders()
            .getFirst(HttpHeaders.AUTHORIZATION);
            
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
            return exchange.getResponse().setComplete();
        }
        
        String token = authHeader.substring(7);
        
        try {
            Jwt jwt = jwtDecoder.decode(token);
            
            // Validate expiration
            if (jwt.getExpiresAt() != null && jwt.getExpiresAt().isBefore(Instant.now())) {
                exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
                return exchange.getResponse().setComplete();
            }
            
            // Add JWT claims to request headers for downstream services
            ServerHttpRequest modifiedRequest = exchange.getRequest().mutate()
                .header("X-User-ID", jwt.getSubject())
                .header("X-User-Roles", String.join(",", 
                    jwt.getClaimAsStringList("roles")))
                .build();
                
            return chain.filter(exchange.mutate().request(modifiedRequest).build());
            
        } catch (JwtException e) {
            exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
            return exchange.getResponse().setComplete();
        }
    }

public class GatewayMetricsFilter implements GlobalFilter {

                Tag.of("method", method),

Zuul API Gateway: Complete Guide

Introduction to Zuul API Gateway

Zuul is a JVM-based router and server-side load balancer developed by Netflix that serves as a gateway service in microservices architecture. It acts as the single entry point for all client requests, providing dynamic routing, monitoring, resiliency, and security capabilities. Zuul's filter-based architecture allows for powerful request and response transformations, making it ideal for API gateway patterns.

Gateway Pattern: Zuul implements the API Gateway pattern, which provides a unified interface to microservices, handling cross-cutting concerns like authentication, rate limiting, and logging in a centralized manner.

Zuul Core Concepts

Dynamic Routing

Route requests to appropriate backend services based on configuration

Filter Framework

Intercept and transform requests/responses using custom filters

Resiliency & Security

Circuit breaking, rate limiting, and security enforcement

Zuul Architecture

Zuul operates on a filter-based architecture where different types of filters handle specific aspects of request processing. The request lifecycle flows through pre-routing filters, routing filters, and post-routing filters, allowing for comprehensive request transformation and monitoring.

@Component
public class AuthenticationFilter extends ZuulFilter {
    
    private static final Logger logger = LoggerFactory.getLogger(AuthenticationFilter.class);
    
    @Override
    public String filterType() {
        return "pre";
    }
    
    @Override
    public int filterOrder() {
        return 1;
    }
    
    @Override
    public boolean shouldFilter() {
        RequestContext ctx = RequestContext.getCurrentContext();
        HttpServletRequest request = ctx.getRequest();
        
        // Skip authentication for certain paths
        String path = request.getRequestURI();
        return !path.startsWith("/api/public/") && 
               !path.equals("/api/health");
    }
    
    @Override
    public Object run() {
        RequestContext ctx = RequestContext.getCurrentContext();
        HttpServletRequest request = ctx.getRequest();
        
        String authHeader = request.getHeader("Authorization");
        
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            // Block the request
            ctx.setSendZuulResponse(false);
            ctx.setResponseStatusCode(HttpStatus.UNAUTHORIZED.value());
            ctx.setResponseBody("{\"error\": \"Missing or invalid authorization header\"}");
            ctx.getResponse().setContentType("application/json");
            return null;
        }
        
        // Validate JWT token
        String token = authHeader.substring(7);
        if (!isValidToken(token)) {
            ctx.setSendZuulResponse(false);
            ctx.setResponseStatusCode(HttpStatus.UNAUTHORIZED.value());
            ctx.setResponseBody("{\"error\": \"Invalid token\"}");
            ctx.getResponse().setContentType("application/json");
            return null;
        }
        
        // Add user info to headers for downstream services
        String userId = extractUserIdFromToken(token);
        ctx.addZuulRequestHeader("X-User-Id", userId);
        
        logger.info("Authenticated request from user: {} to: {}", 
                   userId, request.getRequestURI());
        
        return null;
    }
    
    private boolean isValidToken(String token) {
        // Implement token validation logic
        try {
            Jwts.parser().setSigningKey("secret").parseClaimsJws(token);
            return true;
        } catch (Exception e) {
            return false;
        }
    }
    
    private String extractUserIdFromToken(String token) {
        Claims claims = Jwts.parser()
                          .setSigningKey("secret")
                          .parseClaimsJws(token)
                          .getBody();
        return claims.getSubject();
    }
}

Rate Limiting Filter


@Component
public class RateLimitFilter extends ZuulFilter {
    
    private final RateLimiter rateLimiter;
    private final Map<String, RateLimiter> userRateLimiters = new ConcurrentHashMap<>();
    
    public RateLimitFilter() {
        this.rateLimiter = RateLimiter.create(100); // 100 requests per second globally
    }
    
    @Override
    public String filterType() {
        return "pre";
    }
    
    @Override
    public int filterOrder() {
        return 0; // Run before authentication
    }
    
    @Override
    public boolean shouldFilter() {
        return true;
    }
    
    @Override
    public Object run() {
        RequestContext ctx = RequestContext.getCurrentContext();
        HttpServletRequest request = ctx.getRequest();
        
        // Global rate limiting
        if (!rateLimiter.tryAcquire()) {
            ctx.setSendZuulResponse(false);
            ctx.setResponseStatusCode(HttpStatus.TOO_MANY_REQUESTS.value());
            ctx.setResponseBody("{\"error\": \"Rate limit exceeded\"}");
            return null;
        }
        
        // User-specific rate limiting
        String userId = getUserIdFromRequest(request);
        if (userId != null) {
            RateLimiter userLimiter = userRateLimiters.computeIfAbsent(
                userId, k -> RateLimiter.create(10) // 10 requests per second per user
            );
            
            if (!userLimiter.tryAcquire()) {
                ctx.setSendZuulResponse(false);
                ctx.setResponseStatusCode(HttpStatus.TOO_MANY_REQUESTS.value());
                ctx.setResponseBody("{\"error\": \"User rate limit exceeded\"}");
                return null;
            }
        }
        
        return null;
    }
    
    private String getUserIdFromRequest(HttpServletRequest request) {
        // Extract user ID from token or other means
        String authHeader = request.getHeader("Authorization");
        if (authHeader != null && authHeader.startsWith("Bearer ")) {
            // Extract from JWT token
            return extractUserId(authHeader.substring(7));
        }
        return null;
    }
}

    }
    
    @Override
    public int filterOrder() {

    }
    
    @Override
    public boolean shouldFilter() {
        RequestContext ctx = RequestContext.getCurrentContext();
        return ctx.getThrowable() != null || 
               ctx.getResponseStatusCode() >= 400;
    }
    
    @Override
    public Object run() {
        RequestContext ctx = RequestContext.getCurrentContext();
        Throwable throwable = ctx.getThrowable();
        HttpServletRequest request = ctx.getRequest();
        
        logger.error("Error processing request to {}: {}", 
                    request.getRequestURI(), 
                    throwable != null ? throwable.getMessage() : "Unknown error");
        
        // Custom error response
        ctx.setSendZuulResponse(false);
        ctx.setResponseStatusCode(HttpStatus.INTERNAL_SERVER_ERROR.value());
        
        ErrorResponse errorResponse = new ErrorResponse(
            "GATEWAY_ERROR",
            "Internal server error",
            request.getRequestURI()
        );
        
        ctx.setResponseBody(toJson(errorResponse));
        ctx.getResponse().setContentType("application/json");
        
        return null;
    }
    
    private String toJson(ErrorResponse error) {
        try {
            return new ObjectMapper().writeValueAsString(error);
        } catch (JsonProcessingException e) {
            return "{\"error\": \"Serialization error\"}";
        }
    }

        private String message;
        private String path;
        private Instant timestamp;
        
        public ErrorResponse(String code, String message, String path) {
            this.code = code;
            this.message = message;
            this.path = path;

OpenFeign: Complete Microservices Communication Guide

What is OpenFeign?

OpenFeign is a declarative HTTP client library developed by Netflix and now part of the Spring Cloud ecosystem. It simplifies making HTTP requests to REST services by allowing you to define interfaces with annotations, eliminating the need to write boilerplate code for service communication.

In microservices architecture, OpenFeign acts as a bridge between services, providing a clean, type-safe way to call remote APIs while integrating seamlessly with Spring Boot features like service discovery, load balancing, and circuit breakers.

Core Concept: OpenFeign uses Java interfaces and annotations to create REST clients. At runtime, Spring generates the implementation, handling HTTP requests, serialization/deserialization, and error handling automatically.

// Custom Error Decoder
@Component
public class CustomErrorDecoder implements ErrorDecoder {
    
    private final ErrorDecoder defaultErrorDecoder = new Default();
    private final ObjectMapper objectMapper;
    
    public CustomErrorDecoder(ObjectMapper objectMapper) {
        this.objectMapper = objectMapper;
    }
    
    @Override
    public Exception decode(String methodKey, Response response) {
        // Log the error
        logError(methodKey, response);
        
        try {
            // Read error response body
            String body = Util.toString(response.body().asReader(StandardCharsets.UTF_8));
            ErrorResponse errorResponse = objectMapper.readValue(body, ErrorResponse.class);
            
            // Create appropriate exception based on status code
            return createExceptionFromResponse(methodKey, response, errorResponse);
            
        } catch (IOException e) {
            return defaultErrorDecoder.decode(methodKey, response);
        }
    }
    
    private Exception createExceptionFromResponse(String methodKey, 
                                                Response response, 
                                                ErrorResponse errorResponse) {
        String serviceName = extractServiceName(methodKey);
        
        switch (response.status()) {
            case 400:
                return new ServiceException(serviceName, 
                    errorResponse.getMessage(), 400, "BAD_REQUEST");
                    
            case 404:
                return new ServiceException(serviceName,
                    errorResponse.getMessage(), 404, "NOT_FOUND");
                    
            case 409:
                return new ServiceException(serviceName,
                    errorResponse.getMessage(), 409, "CONFLICT");
                    
            case 422:
                return new ServiceException(serviceName,
                    errorResponse.getMessage(), 422, "UNPROCESSABLE_ENTITY");
                    
            case 500:
                return new ServiceException(serviceName,
                    "Internal server error in " + serviceName, 500, "INTERNAL_ERROR");
                    
            case 503:
                return new ServiceException(serviceName,
                    "Service unavailable: " + serviceName, 503, "SERVICE_UNAVAILABLE");
                    
            default:
                return new ServiceException(serviceName,
                    "Unexpected error from " + serviceName, 
                    response.status(), "UNKNOWN_ERROR");
        }
    }
    
    private String extractServiceName(String methodKey) {
        // methodKey format: UserServiceClient#getUserById(Long)
        if (methodKey.contains("#")) {
            return methodKey.split("#")[0];
        }
        return "unknown-service";
    }
    
    private void logError(String methodKey, Response response) {
        Logger logger = LoggerFactory.getLogger(methodKey.split("#")[0]);
        logger.error("Feign client error - Method: {}, Status: {}, Reason: {}", 
                    methodKey, response.status(), response.reason());
    }
}

@Service
@Transactional
@Slf4j
public class OrderManagementService {
    
    private final UserServiceClient userServiceClient;
    private final ProductServiceClient productServiceClient;
    private final OrderRepository orderRepository;
    private final ObjectMapper objectMapper;
    private final CircuitBreakerFactory circuitBreakerFactory;
    
    public OrderDTO createOrderWithValidation(CreateOrderRequest request) {
        log.info("Creating order for user: {}", request.getUserId());
        
        try {
            // 1. Validate user existence and status
            UserDTO user = validateUser(request.getUserId());
            
            // 2. Validate and process products
            List<OrderItemDTO> orderItems = validateAndProcessProducts(request.getItems());
            
            // 3. Calculate total amount
            BigDecimal totalAmount = calculateTotalAmount(orderItems);
            
            // 4. Create and save order
            Order order = createOrderEntity(user, orderItems, totalAmount);
            order = orderRepository.save(order);
            
            // 5. Update product stock
            updateProductStock(orderItems);
            
            log.info("Order created successfully with ID: {}", order.getId());
            return mapToDTO(order);
            
        } catch (ServiceException e) {
            log.error("Service error while creating order: {}", e.getMessage());
            throw e;
        } catch (Exception e) {
            log.error("Unexpected error while creating order: {}", e.getMessage());
            throw new OrderCreationException("Failed to create order");
        }
    }
    
    private UserDTO validateUser(Long userId) {
        return circuitBreakerFactory.create("userService")
            .run(() -> {
                ResponseEntity<UserDTO> response = userServiceClient.getUserById(userId);
                if (!response.getStatusCode().is2xxSuccessful() || response.getBody() == null) {
                    throw new UserNotFoundException("User not found with ID: " + userId);
                }
                
                UserDTO user = response.getBody();
                if (!UserStatus.ACTIVE.equals(user.getStatus())) {
                    throw new InvalidUserException("User is not active: " + userId);
                }
                
                return user;
            }, throwable -> {
                log.warn("User service unavailable during validation: {}", 
                        throwable.getMessage());
                throw new ServiceUnavailableException("User service is temporarily unavailable");
            });
    }
    
    private List<OrderItemDTO> validateAndProcessProducts(List<OrderItemRequest> items) {
        if (items == null || items.isEmpty()) {
            throw new InvalidOrderException("Order must contain at least one item");
        }
        
        // Get all product IDs
        List<Long> productIds = items.stream()
            .map(OrderItemRequest::getProductId)
            .collect(Collectors.toList());
        
        // Fetch products in batch
        Map<Long, ProductDTO> products = circuitBreakerFactory.create("productService")
            .run(() -> {
                ResponseEntity<List<ProductDTO>> response = 
                    productServiceClient.getProductsByIds(productIds);
                
                if (response.getBody() == null) {
                    return Collections.emptyMap();
                }
                
                return response.getBody().stream()
                    .collect(Collectors.toMap(ProductDTO::getId, Function.identity()));
            }, throwable -> {
                log.warn("Product service unavailable: {}", throwable.getMessage());
                throw new ServiceUnavailableException("Product service is temporarily unavailable");
            });
        
        // Validate each item
        return items.stream()
            .map(item -> {
                ProductDTO product = products.get(item.getProductId());
                if (product == null) {
                    throw new ProductNotFoundException(
                        "Product not found: " + item.getProductId());
                }
                
                if (!product.getActive()) {
                    throw new InvalidProductException(
                        "Product is not active: " + product.getName());
                }
                
                if (product.getStockQuantity() < item.getQuantity()) {
                    throw new InsufficientStockException(
                        "Insufficient stock for product: " + product.getName());
                }
                
                return OrderItemDTO.builder()
                    .productId(product.getId())
                    .productName(product.getName())
                    .quantity(item.getQuantity())
                    .unitPrice(product.getPrice())
                    .build();
            })
            .collect(Collectors.toList());
    }
    
    private void updateProductStock(List<OrderItemDTO> orderItems) {
        orderItems.forEach(item -> {
            try {
                circuitBreakerFactory.create("productService")
                    .run(() -> {
                        productServiceClient.decrementStock(
                            item.getProductId(), item.getQuantity());
                        return null;
                    });
                
            } catch (Exception e) {
                log.error("Failed to update stock for product: {}", item.getProductId(), e);
                // Compensating action or retry logic can be implemented here
            }
        });
    }

Best Practices and Patterns

Best Practices

  • Use meaningful service names in @FeignClient annotation
  • Implement proper error handling with custom ErrorDecoder
  • Use circuit breakers to prevent cascading failures
  • Configure appropriate timeouts for each service
  • Implement retry mechanisms for transient failures
  • Use request interceptors for cross-cutting concerns
  • Implement fallback strategies for critical services
  • Monitor and log Feign client interactions
  • Use DTOs for request/response mapping
  • Test Feign clients with both unit and integration tests

Anti-Patterns to Avoid

  • Direct URL hardcoding in Feign clients
  • Ignoring timeout configurations
  • Not handling circuit breaker states
  • Missing fallback implementations
  • Poor error handling and logging
  • Not monitoring Feign client metrics
  • Ignoring retry mechanisms
  • Not using service discovery
  • Mixing business logic with Feign client calls
