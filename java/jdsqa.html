Q51: Tree Data Structure

Trees
What is a tree data structure? What are its key components?

A tree is a hierarchical, non-linear data structure consisting of nodes connected by edges. It simulates a tree-like structure with a root and branches.

Key Components:

  • Node: Basic unit containing data.
  • Root: Topmost node with no parent.
  • Parent: Node that has children.
  • Child: Node that has a parent.
  • Leaf: Node with no children.
  • Edge: Connection between nodes.
  • Subtree: A node and its descendants.
  • Depth: Number of edges from root to node.
  • Height: Number of edges on longest path from node to leaf.
// Node representation
class Node {
    int data;
    Node left;
    Node right;
    Node(int data) { this.data = data; }
}

Key property: A tree with n nodes has n-1 edges.

Q52: Binary Tree

Trees
What is a binary tree? What are its properties?

A binary tree is a tree data structure where each node has at most two children, referred to as the left child and the right child.

Properties:

  • Each node has 0, 1, or 2 children.
  • The maximum number of nodes at level l is 2^l (root level = 0).
  • Maximum nodes in a binary tree of height h is 2^(h+1) - 1.
  • Minimum height for n nodes is ceil(log₂(n+1)) - 1.
  • Represented using arrays or linked nodes.
// Binary tree node
class BinaryTreeNode {
    int data;
    BinaryTreeNode left;
    BinaryTreeNode right;
}

Types: Full, Complete, Perfect, Balanced, and Degenerate.

Q54: Types of Binary Trees

Trees
What are the different types of binary trees?
  • Full Binary Tree: Every node has either 0 or 2 children.
  • Complete Binary Tree: All levels are filled except possibly the last, which is filled left to right.
  • Perfect Binary Tree: All internal nodes have 2 children, and all leaves are at the same level.

Q55: Tree Traversal

Trees
What is tree traversal? What are the different types?

Tree traversal is the process of visiting each node in a tree exactly once in a specific order.

Types of traversals:

  • Depth-First Search (DFS): Explore as far as possible before backtracking.
    • In-order: Left → Root → Right
    • Pre-order: Root → Left → Right
    • Post-order: Left → Right → Root
  • Breadth-First Search (BFS): Explore level by level (Level-order).
// For a tree:
// 1
// / \
// 2 3
// / \
// 4 5

// In-order: 4, 2, 5, 1, 3
// Pre-order: 1, 2, 4, 5, 3
// Post-order: 4, 5, 2, 3, 1
// Level-order: 1, 2, 3, 4, 5

Choice of traversal depends on the operation being performed.

Q56: In-order Traversal

Trees
What is In-order traversal? When is it used?

In-order traversal visits nodes in the following order: Left Subtree → Root → Right Subtree.

When it's used:

  • To get nodes in sorted order in a BST (ascending).
  • To evaluate expression trees (infix notation).
  • To traverse a tree when the order matters.
void inOrder(Node root) {
    if (root == null) return;
    inOrder(root.left);
    System.out.print(root.data + " ");
    inOrder(root.right);
}

// For BST, prints values in ascending order

Time complexity: O(n) for visiting all nodes.

Space complexity: O(h) for recursion stack (h = height).

Q57: Pre-order Traversal

Trees
What is Pre-order traversal? When is it used?

Pre-order traversal visits nodes in the order: Root → Left Subtree → Right Subtree.

When it's used:

  • To create a copy of a tree.
  • To generate a serialization of a tree.
  • To get the prefix expression of an expression tree.
  • In algorithms where the root needs to be processed before its children.
void preOrder(Node root) {
    if (root == null) return;
    System.out.print(root.data + " ");
    preOrder(root.left);
    preOrder(root.right);
}

Time complexity: O(n).

Space complexity: O(h) for recursion stack.

Q58: Post-order Traversal

Trees
What is Post-order traversal? When is it used?

Post-order traversal visits nodes in the order: Left Subtree → Right Subtree → Root.

When it's used:

  • To delete a tree (children before parent).
  • To evaluate expression trees (postfix notation).
  • To calculate the height of a tree.
  • In algorithms where children need to be processed before the parent.
void postOrder(Node root) {
    if (root == null) return;
    postOrder(root.left);
    postOrder(root.right);
    System.out.print(root.data + " ");
}

Example: Post-order: 4 5 2 3 1 for the earlier tree.

Q59: Level-order Traversal

Trees
What is Level-order traversal? How is it implemented?

Level-order traversal visits nodes level by level, from top to bottom and left to right. It uses a queue to keep track of nodes at each level.

void levelOrder(Node root) {
    if (root == null) return;
    Queue<Node> queue = new LinkedList<>();
    queue.add(root);
    while (!queue.isEmpty()) {
        Node curr = queue.poll();
        System.out.print(curr.data + " ");
        if (curr.left != null) queue.add(curr.left);
        if (curr.right != null) queue.add(curr.right);
    }
}

Time complexity: O(n).

Space complexity: O(n) for the queue (in the worst case).

Use cases:

  • Finding the shortest path in a tree.
  • Finding the minimum depth of a binary tree.
  • BFS traversal.

Q60: Height of a Binary Tree

Trees
How do you find the height of a binary tree?

The height of a binary tree is the number of edges on the longest path from the root to a leaf. (Some definitions use the number of nodes on the path.)

Algorithm:

  • If the node is null, height = -1 (or 0 for node count).
  • Recursively compute the height of the left and right subtrees.
  • Return max(leftHeight, rightHeight) + 1.
int height(Node root) {
    if (root == null) return -1;
    int leftHeight = height(root.left);
    int rightHeight = height(root.right);
    return Math.max(leftHeight, rightHeight) + 1;
}

Time complexity: O(n).

Space complexity: O(h) for recursion stack.

Q61: Balanced Binary Tree Check

Trees
How do you check if a binary tree is balanced?

A binary tree is balanced if for every node, the heights of its left and right subtrees differ by at most 1.

Algorithm (bottom-up):

  • Recursively compute the height of each subtree.
  • If any node's subtree is unbalanced, propagate -1.
  • If the tree is balanced, return the height.
boolean isBalanced(Node root) {
    return checkHeight(root) != -1;
}

int checkHeight(Node root) {
    if (root == null) return 0;
    int left = checkHeight(root.left);
    if (left == -1) return -1;
    int right = checkHeight(root.right);
    if (right == -1) return -1;
    if (Math.abs(left - right) > 1) return -1;
    return Math.max(left, right) + 1;
}

Time complexity: O(n).

Space complexity: O(h).

Q62: Diameter of a Binary Tree

Trees
How do you find the diameter of a binary tree?

The diameter of a binary tree is the number of nodes on the longest path between any two nodes in the tree. It may or may not pass through the root.

Algorithm:

  • For each node, calculate the height of left and right subtrees.
  • The diameter through the node = leftHeight + rightHeight + 1.
  • Track the maximum diameter globally.
int diameter(Node root) {
    int[] max = new int[1];
    height(root, max);
    return max[0];
}

int height(Node root, int[] max) {
    if (root == null) return 0;
    int left = height(root.left, max);
    int right = height(root.right, max);
    max[0] = Math.max(max[0], left + right + 1);
    return Math.max(left, right) + 1;
}

Time complexity: O(n).

Space complexity: O(h).

Q63: Lowest Common Ancestor (LCA)

Trees
What is the lowest common ancestor (LCA) of two nodes in a binary tree?

The Lowest Common Ancestor (LCA) of two nodes is the deepest node that is an ancestor of both nodes.

Algorithm:

  • If the tree is empty, return null.
  • If the current node matches one of the nodes, return it.
  • Search in left and right subtrees.
  • If both sides return a node, the current node is the LCA.
  • If only one side returns a node, return that node.
Node LCA(Node root, Node p, Node q) {
    if (root == null || root == p || root == q)
        return root;
    Node left = LCA(root.left, p, q);
    Node right = LCA(root.right, p, q);
    if (left != null && right != null) return root;
    return left != null ? left : right;
}

Time complexity: O(n).

Space complexity: O(h).

Q64: Identical Trees

Trees
How do you check if two binary trees are identical?

Two binary trees are identical if they have the same structure and the same values at every node.

Algorithm:

  • If both trees are null, return true.
  • If one is null and the other isn't, return false.
  • Compare the data of the current nodes.
  • Recursively check left and right subtrees.
boolean isIdentical(Node a, Node b) {
    if (a == null && b == null) return true;
    if (a == null || b == null) return false;
    return a.data == b.data &&
        isIdentical(a.left, b.left) &&
        isIdentical(a.right, b.right);
}

Time complexity: O(min(n, m)).

Space complexity: O(min(h1, h2)).

Q65: Mirror Image of Binary Tree

Trees
How do you convert a binary tree to its mirror image?

The mirror image of a binary tree is created by swapping the left and right child of every node.

Algorithm (recursive):

  • If the tree is empty, return.
  • Swap the left and right children.
  • Recursively mirror the left and right subtrees.
Node mirror(Node root) {
    if (root == null) return null;
    Node left = mirror(root.left);
    Node right = mirror(root.right);
    root.left = right;
    root.right = left;
    return root;
}

Q67: Perfect Binary Tree

Trees
What is a perfect binary tree?

A perfect binary tree is a binary tree where all internal nodes have exactly 2 children and all leaves are at the same level.

Properties:

  • All leaves are at the same depth.
  • Every internal node has exactly two children.
  • For height h, the tree has 2^(h+1) - 1 nodes.
  • The number of leaf nodes is 2^h.
// Perfect Binary Tree (height = 2)
// 1
// / \
// 2 3
// / \ / \
// 4 5 6 7
// Nodes = 2^(2+1) - 1 = 7

Note: A perfect tree is also a complete and full tree.

Q68: Level Order Traversal (Revisited)

Trees
How do you perform a binary tree level order traversal?

Level order traversal visits nodes level by level using a queue.

void levelOrder(Node root) {
    if (root == null) return;
    Queue<Node> queue = new LinkedList<>();
    queue.add(root);
    while (!queue.isEmpty()) {
        Node curr = queue.poll();
        System.out.print(curr.data + " ");
        if (curr.left != null) queue.add(curr.left);
        if (curr.right != null) queue.add(curr.right);
    }
}

Alternative – level by level with delimiter:

void levelOrderWithLevel(Node root) {
    Queue<Node> q = new LinkedList<>();
    q.add(root);
    q.add(null); // delimiter
    while (!q.isEmpty()) {
        Node curr = q.poll();
        if (curr == null) {
            System.out.println();
            if (!q.isEmpty()) q.add(null);
        } else {
            System.out.print(curr.data + " ");
            if (curr.left != null) q.add(curr.left);
            if (curr.right != null) q.add(curr.right);
        }
    }
}

Q69: Binary Search Tree (BST)

BST
What is a Binary Search Tree (BST)? What are its properties?

A Binary Search Tree (BST) is a binary tree that satisfies the BST property:

Property: For any node, all nodes in its left subtree have values less than the node's value, and all nodes in its right subtree have values greater than the node's value.

Key properties:

  • In-order traversal yields nodes in sorted order.
  • Supports efficient search, insertion, and deletion.
  • Average time complexity: O(log n) (if balanced).
  • Worst-case time complexity: O(n) (if degenerate).

Q70: Insert into BST

BST
How do you insert a node into a BST?

Algorithm:

  • If the tree is empty, create a new node.
  • If the value is less than the current node, go to the left subtree.
  • If the value is greater than the current node, go to the right subtree.
  • Insert the node when a null position is found.
Node insert(Node root, int val) {
    if (root == null) return new Node(val);
    if (val < root.data)
        root.left = insert(root.left, val);
    else if (val > root.data)
        root.right = insert(root.right, val);
    return root;
}

Time complexity: Average O(log n), worst O(n).

Q71: Search in BST

BST
How do you search for a node in a BST?

Algorithm:

  • If the tree is empty or the node is found, return the node.
  • If the value is less than the current node, search in the left subtree.
  • If the value is greater than the current node, search in the right subtree.
Node search(Node root, int val) {
    if (root == null || root.data == val)
        return root;
    if (val < root.data)
        return search(root.left, val);
    return search(root.right, val);
}

Time complexity: Average O(log n), worst O(n).

Q72: Delete from BST

BST
How do you delete a node from a BST?

Algorithm:

  • Search for the node to delete.
  • If found, handle three cases:
    • Case 1: Leaf node – simply remove it.
    • Case 2: Node with one child – replace with the child.
    • Case 3: Node with two children – find inorder successor (smallest in right subtree) or inorder predecessor (largest in left subtree), copy its value, and delete the successor.
Node delete(Node root, int val) {
    if (root == null) return null;
    if (val < root.data)
        root.left = delete(root.left, val);
    else if (val > root.data)
        root.right = delete(root.right, val);
    else {
        if (root.left == null) return root.right;
        if (root.right == null) return root.left;
        Node successor = findMin(root.right);
        root.data = successor.data;
        root.right = delete(root.right, successor.data);
    }
    return root;
}

Q73: BST Deletion Cases

BST
What are the different cases for deleting a node from BST?
  • Case 1: Leaf Node (No Children)
    • Simply remove the node by setting the parent's reference to null.
  • Case 2: Node with One Child
    • Replace the node with its only child.
    • The child takes the place of the deleted node.
  • Case 3: Node with Two Children
    • Find the in-order successor (smallest in right subtree) or in-order predecessor (largest in left subtree).
    • Copy the successor's value to the node.
    • Recursively delete the successor (which will be Case 1 or 2).

Q75: Min & Max in BST

BST
How do you find the minimum and maximum values in a BST?

Minimum: The leftmost node in the BST (go left until null).

Maximum: The rightmost node in the BST (go right until null).

Node findMin(Node root) {
    if (root == null) return null;
    while (root.left != null) root = root.left;
    return root;
}

Node findMax(Node root) {
    if (root == null) return null;
    while (root.right != null) root = root.right;
    return root;
}

// Min = 2, Max = 8

Q76: AVL Tree

BST
What is an AVL Tree? Why is it needed?

An AVL Tree (Adelson-Velsky and Landis) is a self-balancing Binary Search Tree where the heights of the left and right subtrees of every node differ by at most 1 (balance factor = -1, 0, or 1).

Why is it needed?

  • Regular BST operations can degenerate to O(n) in the worst case (when elements are inserted in sorted order).
  • AVL trees maintain balance automatically, guaranteeing O(log n) operations.
  • After insertions and deletions, rotations (left, right, left-right, right-left) are performed to restore balance.
// AVL property: |height(left) - height(right)| ≤ 1
// Each node stores its height
class AVLNode {
    int data, height;
    AVLNode left, right;
}

Drawback: AVL trees require more rotations during insertion/deletion compared to Red-Black trees.

Q78: Red-Black Tree

BST
What is a Red-Black Tree?

A Red-Black Tree is a self-balancing BST where each node has an extra bit representing its color (red or black).

Properties:

  • Every node is either red or black.
  • The root is always black.
  • All leaves (null nodes) are black.
  • Red nodes cannot have red children (no two consecutive red nodes).
  • Every path from a node to its null leaves has the same number of black nodes.

Advantages over AVL:

  • Requires fewer rotations during insertion/deletion.
  • Used in Java's TreeMap and TreeSet.
  • Provides O(log n) performance while being more efficient than AVL for frequent modifications.

Q79: Heap Data Structure

Heaps
What is a heap data structure?

A heap is a complete binary tree that satisfies the heap property:

  • Max-Heap: For every node, the value of the node is ≥ the values of its children (parent is larger).
  • Min-Heap: For every node, the value of the node is ≤ the values of its children (parent is smaller).

Key features:

  • Implementable as an array (level-order traversal).
  • For a node at index i:
    • Parent: (i-1)/2
    • Left child: 2*i + 1
    • Right child: 2*i + 2
  • Root is the maximum (max-heap) or minimum (min-heap) element.

// 20 10 35
// Array: [50, 30, 40, 20, 10, 35]

Q81: Applications of Heaps

Heaps
What are the applications of heaps?
  • Priority Queues: Heaps are the underlying data structure for priority queues.
  • Heap Sort: An efficient O(n log n) sorting algorithm.
  • Graph Algorithms: Dijkstra's shortest path, Prim's Minimum Spanning Tree.
  • Kth Largest/Smallest: Finding the kth largest or smallest element in an array.
  • Merge k Sorted Lists: Using a min-heap to merge multiple sorted lists.
  • Median Finding: Using two heaps (min and max) to find the median of a stream.
  • Event-driven Simulation: Scheduling events by priority.
  • Operating Systems: Process scheduling.

Why heaps are preferred? They provide O(log n) insertion and O(log n) removal of the max/min element.

Q83: Insert into Heap

Heaps
How do you insert an element into a heap?

Algorithm (Max-Heap):

  • Add the new element at the end of the heap (array).
  • Heapify Up (Bubble Up): While the parent is smaller than the new element, swap them.
  • Repeat until the heap property is restored.
void insert(int val) {
    heap.add(val); // add to end
    int i = heap.size() - 1;
    while (i > 0) {
        int parent = (i - 1) / 2;
        if (heap.get(parent) >= heap.get(i)) break;
        swap(i, parent);
        i = parent;
    }
}

Time complexity: O(log n).

Space complexity: O(1) additional space.

Q84: Remove Root from Heap

Heaps
How do you remove the root element from a heap?

Algorithm (Max-Heap):

  • Remove the root and replace it with the last element in the heap.
  • Remove the last element.
  • Heapify Down (Bubble Down): While the current node has children and is smaller than either child, swap with the larger child.
  • Repeat until the heap property is restored.
int extractMax() {
    if (heap.isEmpty()) return -1;
    int max = heap.get(0);
    int last = heap.remove(heap.size() - 1);
    if (!heap.isEmpty()) {
        heap.set(0, last);
        heapifyDown(0);
    }
    return max;
}

Time complexity: O(log n).

Q85: Heapify

Heaps
What is heapify? How does it work?

Heapify is the process of converting an arbitrary array into a valid heap.

Algorithm (Max-Heapify):

  • Start from the last internal node (index n/2 - 1).
  • For each node, apply heapify-down to ensure the subtree is a valid heap.
  • Move upward to the root.
void heapify(int[] arr) {
    int n = arr.length;
    for (int i = n/2 - 1; i >= 0; i--) {
        heapifyDown(arr, n, i);
    }
}

void heapifyDown(int[] arr, int n, int i) {
    int largest = i;
    int left = 2*i + 1;
    int right = 2*i + 2;
    if (left < n && arr[left] > arr[largest]) largest = left;
    if (right < n && arr[right] > arr[largest]) largest = right;
    if (largest != i) {
        swap(arr, i, largest);
        heapifyDown(arr, n, largest);
    }
}

Time complexity: O(n) – bottom-up approach is efficient.

  • O(1): Accessing the root (max/min) is instant.
  • O(n): Heapify builds the heap from an arbitrary array in linear time.
  • O(n log n): Heap sort does n extractions, each O(log n).

Space complexity: O(1) for in-place operations.

Q87: Priority Queue

Heaps
What is a priority queue? How is it implemented using a heap?

A priority queue is an abstract data type where each element has a priority. Elements are removed based on their priority (highest priority first).

Implementation using Heap:

  • Max-Heap: For max-priority queue (highest priority first).
  • Min-Heap: For min-priority queue (lowest priority first).
  • Operations map directly to heap operations:
    • insert → heap insert
    • extractMax / extractMin → heap extract root
    • peek → heap root access
// Java PriorityQueue (min-heap by default)
PriorityQueue<Integer> pq = new PriorityQueue<>();
pq.add(10);
pq.add(5);
pq.add(20);
System.out.println(pq.poll()); // 5 (min element)

Use cases: Dijkstra's algorithm, task scheduling, Huffman coding.

Q88: Heap Sort

Heaps
How do you implement heap sort?

Heap Sort is an in-place sorting algorithm with O(n log n) time complexity.

Algorithm:

  • Build a max-heap from the array (heapify).
  • Repeatedly swap the root (max element) with the last element.
  • Reduce the heap size by 1 and heapify the root.
  • Repeat until the entire array is sorted.
void heapSort(int[] arr) {
    int n = arr.length;
    // Build max-heap
    for (int i = n/2 - 1; i >= 0; i--) {
        heapify(arr, n, i);
    }
    // Extract elements one by one
    for (int i = n - 1; i > 0; i--) {
        swap(arr, 0, i);
        heapify(arr, i, 0);
    }
}

Time complexity: O(n log n).

Space complexity: O(1) – in-place sorting.

Q89: Kth Largest Element

Heaps
How do you find the kth largest element in an array using a heap?

Algorithm (using Min-Heap):

  • Create a min-heap of size k.
  • Add the first k elements to the heap.
  • For each remaining element, if it is larger than the root (smallest in heap), remove the root and insert the new element.
  • After processing all elements, the root of the heap is the kth largest element.
int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> minHeap = new PriorityQueue<>(k);
    for (int num : nums) {
        minHeap.add(num);
        if (minHeap.size() > k) {
            minHeap.poll();
        }
    }
    return minHeap.peek();
}

Time complexity: O(n log k).

Space complexity: O(k).

Q90: Merge k Sorted Lists

Heaps
How do you merge k sorted lists using a heap?

Algorithm:

  • Create a min-heap of size k.
  • Add the first element of each list to the heap (with list index).
  • Repeatedly remove the minimum element from the heap and add it to the result.
  • If the list from which the element was removed has more elements, add the next element to the heap.
  • Continue until the heap is empty.
Node mergeKLists(List<Node> lists) {
    PriorityQueue<Node> heap = new PriorityQueue<>(
        (a, b) -> a.val - b.val);
    for (Node head : lists) {
        if (head != null) heap.add(head);
    }
    Node dummy = new Node(0);
    Node tail = dummy;
    while (!heap.isEmpty()) {
        Node curr = heap.poll();
        tail.next = curr;
        tail = curr;
        if (curr.next != null) heap.add(curr.next);
    }
    return dummy.next;
}

Time complexity: O(n log k) where n is total elements, k is number of lists.

Q96: Graph Traversal

Graphs
What is graph traversal? What are the types?

Graph traversal is the process of visiting all vertices in a graph systematically.

Types:

  • Depth-First Search (DFS): Explores as far as possible along a branch before backtracking. Uses a stack (recursion).
  • Breadth-First Search (BFS): Explores all neighbors at the current level before moving to the next. Uses a queue.
// DFS (recursive)
void dfs(Graph g, int v, boolean[] visited) {
    visited[v] = true;
    for (int neighbor : g.adj[v]) {
        if (!visited[neighbor]) dfs(g, neighbor, visited);
    }
}

// BFS (queue)
void bfs(Graph g, int start) {
    Queue<Integer> q = new LinkedList<>();
    boolean[] visited = new boolean[g.V];
    visited[start] = true;
    q.add(start);
    while (!q.isEmpty()) {
        int v = q.poll();
        for (int neighbor : g.adj[v]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.add(neighbor);
            }
        }
    }
}

Q97: Depth-First Search (DFS)

Graphs
What is Depth-First Search (DFS)? How does it work?

Depth-First Search (DFS) is a graph traversal algorithm that explores as far as possible along each branch before backtracking.

Algorithm:

  • Start at a given vertex and mark it as visited.
  • Recursively visit each unvisited neighbor.
  • Backtrack when no more unvisited neighbors exist.
void dfs(Graph g, int v, boolean[] visited) {
    visited[v] = true;
    System.out.print(v + " ");
    for (int neighbor : g.getNeighbors(v)) {
        if (!visited[neighbor]) {
            dfs(g, neighbor, visited);
        }
    }
}

Time complexity: O(V + E).

Space complexity: O(V) for recursion stack.

Use cases: Finding connected components, topological sorting, detecting cycles.

Q98: Breadth-First Search (BFS)

Graphs
What is Breadth-First Search (BFS)? How does it work?

Breadth-First Search (BFS) is a graph traversal algorithm that explores all neighbors at the current level before moving to the next level.

Algorithm:

  • Start at a given vertex and mark it as visited.
  • Add it to a queue.
  • While the queue is not empty, remove a vertex, process it, and add all unvisited neighbors to the queue.
void bfs(Graph g, int start) {
    Queue<Integer> q = new LinkedList<>();
    boolean[] visited = new boolean[g.V];
    visited[start] = true;
    q.add(start);
    while (!q.isEmpty()) {
        int v = q.poll();
        System.out.print(v + " ");
        for (int neighbor : g.getNeighbors(v)) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.add(neighbor);
            }
        }
    }
}

Time complexity: O(V + E).

Space complexity: O(V) for the queue.

Use cases: Shortest path in unweighted graphs, level-order traversal.
