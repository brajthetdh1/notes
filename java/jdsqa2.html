Q1: Data Structure – Importance

Conceptual
What is a data structure and why is it important in software development?

A data structure is a way of organizing, storing, and managing data in a computer's memory so that it can be accessed and modified efficiently.

Importance:

  • Efficiency: Proper data structures enable optimal time and space complexity.
  • Data Management: Organizes data for easy access, insertion, deletion, and searching.
  • Problem Solving: Choosing the right data structure is key to solving problems effectively.
  • Performance: Affects the speed and resource usage of algorithms.
  • Reusability: Standard data structures are reusable across applications.

Analogy: Data structures are like tools in a toolbox – using the right tool for the job makes the work easier and faster.

Q3: Abstract Data Type (ADT)

Conceptual
What is an Abstract Data Type (ADT)? How is it different from a data structure?

An Abstract Data Type (ADT) is a mathematical model for data types that defines the behavior (operations) but not the implementation. It specifies what operations can be performed, not how they are implemented.

Key differences:

  • ADT: High-level description of operations (e.g., Stack – push, pop).
  • Data Structure: Concrete implementation of an ADT (e.g., Stack implemented with an array or linked list).
// ADT: Stack operations (abstract)
// push(value), pop(), peek(), isEmpty()

// Data Structure: Concrete implementation
class Stack {
    int[] arr; // using array
    void push(int val) { ... }
    int pop() { ... }
}

Analogy: ADT is like a recipe, and the data structure is the actual dish you cook.

Q5: Time Complexity & Big O

Conceptual
What is time complexity? Explain Big O, Big Omega, and Big Theta notations.

Time complexity is a measure of how the runtime of an algorithm grows as the input size grows.

  • Big O (O): Upper bound (worst-case). E.g., O(n²).
  • Big Omega (Ω): Lower bound (best-case). E.g., Ω(n).
  • Big Theta (Θ): Tight bound (average-case). E.g., Θ(n log n).
ComplexityNameExample
O(1)ConstantArray access
O(log n)LogarithmicBinary search
O(n)LinearFinding max
O(n log n)LinearithmicMerge sort
O(n²)QuadraticBubble sort

Key point: Big O is most commonly used to analyze the worst-case performance of algorithms.

Q6: Space Complexity

Conceptual
What is space complexity? Why is it important?

Space complexity is a measure of how much memory an algorithm uses as the input size grows.

It includes:

  • Fixed space: Memory for constants, variables, and program code.
  • Variable space: Memory for input, output, and auxiliary space (e.g., recursion stack).

Why important?

  • Memory is a limited resource.
  • Helps optimize memory usage in embedded systems.
  • Prevents memory exhaustion in large-scale applications.
  • Trade-off between time and space (e.g., caching).

Example: Recursive algorithms often have O(n) space complexity due to the call stack, while iterative versions use O(1).

Q16: Concept of Hashing

Conceptual
What is the concept of hashing? How does it work?

Hashing is the process of mapping data of arbitrary size to fixed-size values (hash codes) using a hash function.

How it works:

  • A key is provided as input to a hash function.
  • The hash function computes an index (hash code) where the key-value pair is stored.
  • This enables O(1) average-time for operations.
// Simple hash function
int hash(String key) {
    int sum = 0;
    for (char c : key.toCharArray()) {
        sum += c;
    }
    return sum % tableSize;
}

Key properties:

  • Deterministic: Same input always produces the same output.
  • Uniform distribution: Distributes keys evenly across the table.
  • Fast computation: The hash function should be efficient.

Q17: Collision in Hashing

Conceptual
What is collision in hashing? How can it be resolved?

A collision occurs when two different keys produce the same hash code.

Collision Resolution Techniques:

  • 1. Chaining (Separate Chaining): Each bucket contains a linked list of entries. Collisions are stored in the list.
  • 2. Open Addressing: Find another empty slot in the table.
    • Linear Probing: Check the next slot (i+1, i+2, ...).
    • Quadratic Probing: Check slots at i+1², i+2², ... .
    • Double Hashing: Use a second hash function.
  • 3. Coalesced Hashing: Combination of chaining and open addressing.
// Chaining example
index = hash(key1) = 5
index = hash(key2) = 5 // collision
// Both stored in bucket 5's linked list

Q20: Concept of Recursion

Conceptual
What is the concept of recursion? How does it relate to data structures?

Recursion is a technique where a function calls itself to solve a smaller instance of the same problem.

Components:

  • Base Case: The terminating condition that stops recursion.
  • Recursive Case: The function calls itself with a smaller input.

Relation to data structures:

  • Trees: Traversal (in-order, pre-order, post-order) is naturally recursive.
  • Linked Lists: Many operations can be implemented recursively.
  • Divide and Conquer: Algorithms like merge sort, quick sort use recursion.
// Recursive factorial
int factorial(int n) {
    if (n <= 1) return 1; // Base case
    return n * factorial(n - 1); // Recursive case
}

Note: Recursion has space complexity of O(h) due to the call stack.

Q24: Amortized Analysis

Conceptual
What is the concept of amortized analysis?

Amortized analysis is a method of analyzing the average time complexity of operations over a sequence of operations, rather than the worst-case time of a single operation.

Why it matters:

  • Some operations may be expensive, but when averaged over many operations, the cost is low.
  • Used to analyze data structures like dynamic arrays (ArrayList) and hash tables.

Example: Dynamic Array

  • Appending an element is O(1) most of the time.
  • When the array is full, it doubles in size, which is O(n) but happens rarely.
  • Amortized time complexity: O(1) per operation.
// Dynamic array resizing
// 1, 2, 4, 8, 16 ... capacity doubling
// n insertions cost O(n) total → O(1) amortized per insertion

Techniques: Aggregation, Accounting, Potential method.

Q26: Stack using Array

Technical
How do you implement a stack using an array? Write the basic operations.
class Stack {
    int[] arr;
    int top;
    int capacity;

    Stack(int capacity) {
        this.capacity = capacity;
        arr = new int[capacity];
        top = -1;
    }

    void push(int val) {
        if (top == capacity - 1) {
            System.out.println("Stack Overflow");
            return;
        }
        arr[++top] = val;
    }

    int pop() {
        if (top == -1) {
            System.out.println("Stack Underflow");
            return -1;
        }
        return arr[top--];
    }

    int peek() {
        return top == -1 ? -1 : arr[top];
    }

    boolean isEmpty() { return top == -1; }
}

Time complexity: All operations are O(1).

Q28: Queue using Array

Technical
How do you implement a queue using an array? Write the basic operations.
class Queue {
    int[] arr;
    int front, rear, size, capacity;

    Queue(int capacity) {
        this.capacity = capacity;
        arr = new int[capacity];
        front = 0;
        rear = -1;
        size = 0;
    }

    void enqueue(int val) {
        if (size == capacity) {
            System.out.println("Queue Overflow");
            return;
        }
        rear = (rear + 1) % capacity;
        arr[rear] = val;
        size++;
    }

    int dequeue() {
        if (size == 0) {
            System.out.println("Queue Underflow");
            return -1;
        }
        int val = arr[front];
        front = (front + 1) % capacity;
        size--;
        return val;
    }

    int peek() { return size == 0 ? -1 : arr[front]; }
    boolean isEmpty() { return size == 0; }
}

Note: Uses circular array for efficient space utilization.

Q29: Queue using Linked List

Technical
How do you implement a queue using a linked list? Write the basic operations.
class Node {
    int data;
    Node next;
    Node(int data) { this.data = data; }
}

class Queue {
    Node front, rear;

    void enqueue(int val) {
        Node newNode = new Node(val);
        if (rear == null) {
            front = rear = newNode;
            return;
        }
        rear.next = newNode;
        rear = newNode;
    }

    int dequeue() {
        if (front == null) {
            System.out.println("Queue Underflow");
            return -1;
        }
        int val = front.data;
        front = front.next;
        if (front == null) rear = null;
        return val;
    }

    int peek() { return front == null ? -1 : front.data; }
    boolean isEmpty() { return front == null; }
}

Advantages: No size limit, dynamic memory allocation.

Q31: Doubly Linked List

Technical
How do you implement a doubly linked list? What are its advantages?
class Node {
    int data;
    Node prev, next;
    Node(int data) { this.data = data; }
}

class DoublyLinkedList {
    Node head, tail;

    void insertAtHead(int val) {
        Node newNode = new Node(val);
        if (head == null) {
            head = tail = newNode;
            return;
        }
        newNode.next = head;
        head.prev = newNode;
        head = newNode;
    }

    void deleteNode(Node node) {
        if (node.prev != null) node.prev.next = node.next;
        else head = node.next;
        if (node.next != null) node.next.prev = node.prev;
        else tail = node.prev;
    }
}

Advantages over singly linked list:

  • Can traverse in both directions (forward and backward).
  • Deletion of a given node is O(1) (with reference to the node).
  • Insertion before a given node is O(1).

Q32: Cycle Detection in Linked List

Technical
How do you detect a cycle in a linked list? (Floyd's Algorithm)

Floyd's Cycle Detection Algorithm (Tortoise and Hare):

  • Use two pointers: slow (moves one step) and fast (moves two steps).
  • If there is a cycle, the fast pointer will eventually meet the slow pointer.
  • If the fast pointer reaches null, there is no cycle.
boolean hasCycle(Node head) {
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}

Time complexity: O(n). Space complexity: O(1).

Finding the start of the cycle: When slow and fast meet, reset slow to head and move both one step at a time; the meeting point is the cycle start.

Q33: Reverse Linked List

Technical
How do you reverse a linked list iteratively and recursively?

Iterative:

Node reverseIterative(Node head) {
    Node prev = null, curr = head, next = null;
    while (curr != null) {
        next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}

Recursive:

Node reverseRecursive(Node head) {
    if (head == null || head.next == null) return head;
    Node newHead = reverseRecursive(head.next);
    head.next.next = head;
    head.next = null;
    return newHead;
}

Time complexity: O(n). Space: O(1) iterative, O(n) recursive.

Q34: Middle Node of Linked List

Technical
How do you find the middle node of a linked list?

Two-pointer approach:

  • Use slow (one step) and fast (two steps) pointers.
  • When fast reaches the end, slow is at the middle.
Node findMiddle(Node head) {
    Node slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}

Time complexity: O(n). Space complexity: O(1).

Note: If the list has even number of nodes, returns the second middle node.

Q35: Remove Duplicates from Sorted Linked List

Technical
How do you remove duplicates from a sorted linked list?
Node removeDuplicates(Node head) {
    Node curr = head;
    while (curr != null && curr.next != null) {
        if (curr.data == curr.next.data) {
            curr.next = curr.next.next;
        } else {
            curr = curr.next;
        }
    }
    return head;
}

Time complexity: O(n). Space complexity: O(1).

Note: Works only for sorted linked lists.

Q36: Merge Two Sorted Linked Lists

Technical
How do you merge two sorted linked lists?
Node merge(Node a, Node b) {
    Node dummy = new Node(0);
    Node tail = dummy;
    while (a != null && b != null) {
        if (a.data <= b.data) {
            tail.next = a;
            a = a.next;
        } else {
            tail.next = b;
            b = b.next;
        }
        tail = tail.next;
    }
    tail.next = (a != null) ? a : b;
    return dummy.next;
}

Time complexity: O(n + m).

Space complexity: O(1) (in-place).

Q37: Binary Search on Array

Technical
How do you implement binary search on a sorted array?
int binarySearch(int[] arr, int target) {
    int left = 0, right = arr.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target) return mid;
        if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}

Time complexity: O(log n).

Space complexity: O(1) iterative, O(log n) recursive.

Note: Binary search requires a sorted array.

Q38: First and Last Occurrence

Technical
How do you find the first and last occurrence of an element in a sorted array?

Algorithm: Use binary search to find the first occurrence (leftmost) and last occurrence (rightmost).

int findFirst(int[] arr, int target) {
    int left = 0, right = arr.length - 1, result = -1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target) {
            result = mid;
            right = mid - 1;
        } else if (arr[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return result;
}

To find last occurrence: Set left = mid + 1 when target is found.

Time complexity: O(log n).

Q39: Maximum Subarray Sum (Kadane's)

Technical
How do you find the maximum subarray sum? (Kadane's Algorithm)

Kadane's Algorithm finds the maximum sum of a contiguous subarray in O(n) time.

int maxSubarraySum(int[] arr) {
    int maxEndingHere = arr[0];
    int maxSoFar = arr[0];
    for (int i = 1; i < arr.length; i++) {
        maxEndingHere = Math.max(arr[i], maxEndingHere + arr[i]);
        maxSoFar = Math.max(maxSoFar, maxEndingHere);
    }
    return maxSoFar;
}

Time complexity: O(n). Space complexity: O(1).

Q40: Two Sum Problem

Technical
How do you find the two numbers in an array that sum to a target? (Two Sum)

Hash Map approach (optimal):

int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (map.containsKey(complement)) {
            return new int[]{map.get(complement), i};
        }
        map.put(nums[i], i);
    }
    return new int[]{-1, -1};
}

Time complexity: O(n). Space complexity: O(n).

Alternative (two-pointer): O(n log n) with sorting.

Q41: Longest Substring Without Repeating

Technical
How do you find the longest substring without repeating characters?

Sliding Window approach:

int lengthOfLongestSubstring(String s) {
    int n = s.length(), maxLen = 0;
    Map<Character, Integer> map = new HashMap<>();
    int left = 0;
    for (int right = 0; right < n; right++) {
        if (map.containsKey(s.charAt(right))) {
            left = Math.max(left, map.get(s.charAt(right)) + 1);
        }
        map.put(s.charAt(right), right);
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}

Time complexity: O(n). Space complexity: O(min(m, n)).

Example: "abcabcbb" → longest = "abc" (length 3).

Q42: Palindrome Check

Technical
How do you check if a string is a palindrome?

Two-pointer approach:

boolean isPalindrome(String s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        if (s.charAt(left) != s.charAt(right)) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

Time complexity: O(n). Space complexity: O(1).

Alternative: Using recursion or string reversal.

Q43: Reverse String using Stack

Technical
How do you reverse a string using a stack?

Algorithm:

  • Push all characters of the string onto the stack.
  • Pop characters from the stack to build the reversed string.
String reverse(String s) {
    Stack<Character> stack = new Stack<>();
    for (char c : s.toCharArray()) stack.push(c);
    StringBuilder sb = new StringBuilder();
    while (!stack.isEmpty()) sb.append(stack.pop());
    return sb.toString();
}

Time complexity: O(n). Space complexity: O(n).

Q45: Heap Sort

void heapSort(int[] arr) {
    int n = arr.length;
    // Build max-heap
    for (int i = n/2 - 1; i >= 0; i--) heapify(arr, n, i);
    // Extract elements one by one
    for (int i = n - 1; i > 0; i--) {
        swap(arr, 0, i);
        heapify(arr, i, 0);
    }
}

Q46: Kth Largest Element

Technical
How do you find the kth largest element in an array?

Using Min-Heap (O(n log k)):

int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> heap = new PriorityQueue<>(k);
    for (int num : nums) {
        heap.add(num);
        if (heap.size() > k) heap.poll();
    }
    return heap.peek();
}

Alternative (QuickSelect): O(n) average, O(n²) worst.

Q47: BST Insert, Delete, Search

Technical
How do you implement a binary search tree (BST) with insert, delete, and search?
class BST {
    Node root;

    void insert(int val) { root = insertRec(root, val); }
    Node insertRec(Node root, int val) {
        if (root == null) return new Node(val);
        if (val < root.data) root.left = insertRec(root.left, val);
        else if (val > root.data) root.right = insertRec(root.right, val);
        return root;
    }

    boolean search(int val) { return searchRec(root, val); }
    boolean searchRec(Node root, int val) {
        if (root == null) return false;
        if (root.data == val) return true;
        return val < root.data ? searchRec(root.left, val) : searchRec(root.right, val);
    }

    void delete(int val) { root = deleteRec(root, val); }
    Node deleteRec(Node root, int val) {
        if (root == null) return null;
        if (val < root.data) root.left = deleteRec(root.left, val);
        else if (val > root.data) root.right = deleteRec(root.right, val);

Q48: Lowest Common Ancestor in BST

Technical
How do you find the Lowest Common Ancestor (LCA) in a BST?

Algorithm (iterative):

  • Start from the root.
  • If both values are less than the current node, go left.
  • If both values are greater than the current node, go right.
  • Otherwise, the current node is the LCA.
Node LCA(Node root, int p, int q) {
    while (root != null) {
        if (p < root.data && q < root.data)
            root = root.left;
        else if (p > root.data && q > root.data)
            root = root.right;
        else return root;
    }
    return null;
}

Time complexity: O(h) where h is height of the tree.

Example: In BST [2,3,4,5,6,7,8], LCA of 2 and 8 is 5.

void levelOrder(Node root) {

}
