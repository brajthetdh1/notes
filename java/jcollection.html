Collections Topics

Java Collections Framework Overview

The Java Collections Framework provides a unified architecture for storing and manipulating groups of objects. It includes interfaces, implementations, and algorithms that help developers work with data structures efficiently.

Core Interfaces

  • List - Ordered collection with duplicates
  • Set - Collection with no duplicates
  • Map - Key-value pairs collection
  • Queue - FIFO collection
  • Deque - Double-ended queue

Key Benefits

  • Reduces programming effort
  • Increases performance and quality
  • Provides interoperability
  • Easy to learn and use

List Interface

The List interface represents an ordered collection (sequence). Lists allow duplicate elements and provide positional access to elements.

List Implementations

ArrayList

Resizable array implementation

List

Dynamic array that grows automatically. Fast random access but slower insertions/removals in the middle.

Get by index: O(1)
Add/Remove (end): O(1)
Add/Remove (middle): O(n)
Search: O(n)

LinkedList

Doubly-linked list implementation

List & Deque

Doubly-linked list implementation. Fast insertions/removals but slower random access.

Get by index: O(n)
Add/Remove (end): O(1)
Add/Remove (middle): O(1)
Search: O(n)

Vector

Synchronized resizable array

List

Thread-safe version of ArrayList. Synchronized methods make it slower than ArrayList.

Get by index: O(1)
Add/Remove (end): O(1)
Add/Remove (middle): O(n)
Search: O(n)

List Operations & Examples

Basic List Operations

import java.util.*;

public class ListExamples {
    public static void main(String[] args) {
        // ArrayList example
        List<String> arrayList = new ArrayList<>();
        
        // Adding elements
        arrayList.add("Apple");
        arrayList.add("Banana");
        arrayList.add("Orange");
        arrayList.add(1, "Mango"); // Insert at specific position
        
        System.out.println("ArrayList: " + arrayList);
        
        // Accessing elements
        String first = arrayList.get(0);
        System.out.println("First element: " + first);
        
        // Removing elements
        arrayList.remove("Banana");
        arrayList.remove(0);
        
        // Iterating through list
        System.out.println("Iterating with for-each:");
        for (String fruit : arrayList) {
            System.out.println(fruit);
        }
        
        System.out.println("Iterating with iterator:");
        Iterator<String> iterator = arrayList.iterator();
        while (iterator.hasNext()) {
            System.out.println(iterator.next());
        }
        
        // List-specific methods
        int size = arrayList.size();
        boolean isEmpty = arrayList.isEmpty();
        boolean contains = arrayList.contains("Orange");
        int index = arrayList.indexOf("Orange");
        
        System.out.println("Size: " + size);
        System.out.println("Is empty: " + isEmpty);
        System.out.println("Contains Orange: " + contains);
        System.out.println("Index of Orange: " + index);
    }
}

LinkedList Specific Operations

import java.util.*;

public class LinkedListExample {
    public static void main(String[] args) {
        // LinkedList as List and Deque
        LinkedList<String> linkedList = new LinkedList<>();
        
        // Adding elements
        linkedList.add("First");
        linkedList.add("Second");
        linkedList.addFirst("Very First"); // Add at beginning
        linkedList.addLast("Very Last");   // Add at end
        
        System.out.println("LinkedList: " + linkedList);
        
        // Queue operations
        linkedList.offer("Offered"); // Add to end
        String peeked = linkedList.peek(); // Get first without removal
        String polled = linkedList.poll(); // Remove and return first
        
        System.out.println("Peeked: " + peeked);
        System.out.println("Polled: " + polled);
        System.out.println("After queue operations: " + linkedList);
        
        // Stack operations
        linkedList.push("Pushed"); // Push to front
        String popped = linkedList.pop(); // Pop from front
        
        System.out.println("Popped: " + popped);
        System.out.println("After stack operations: " + linkedList);
        
        // Deque operations
        linkedList.offerFirst("Front");
        linkedList.offerLast("Back");
        String first = linkedList.getFirst();
        String last = linkedList.getLast();
        
        System.out.println("First: " + first);
        System.out.println("Last: " + last);
        System.out.println("Final LinkedList: " + linkedList);
    }
}

List Implementation Guidelines

  • Use ArrayList when you need frequent random access
  • Use LinkedList when you need frequent insertions/removals
  • Use Vector only for thread-safe requirements (consider CopyOnWriteArrayList)
  • Use LinkedList when you need Queue/Deque functionality

Set Interface

The Set interface represents a collection that contains no duplicate elements. It models the mathematical set abstraction.

Set Implementations

HashSet

Hash table implementation

Set

Backed by a HashMap. No ordering guarantees. Fastest Set implementation.

Add: O(1)
Remove: O(1)
Contains: O(1)
Iteration: O(n)

LinkedHashSet

Hash table + linked list

Set

Maintains insertion order. Slightly slower than HashSet due to linked list maintenance.

Add: O(1)
Remove: O(1)
Contains: O(1)
Iteration: O(n)

TreeSet

Red-Black tree implementation

SortedSet

Elements are sorted. Implements NavigableSet for navigation methods.

Add: O(log n)
Remove: O(log n)
Contains: O(log n)
Iteration: O(n)

Set Operations & Examples

Basic Set Operations

import java.util.*;

public class SetExamples {
    public static void main(String[] args) {
        // HashSet example
        Set<String> hashSet = new HashSet<>();
        
        // Adding elements (duplicates are ignored)
        hashSet.add("Apple");
        hashSet.add("Banana");
        hashSet.add("Orange");
        hashSet.add("Apple"); // Duplicate - will be ignored
        
        System.out.println("HashSet: " + hashSet);
        System.out.println("Size: " + hashSet.size()); // 3, not 4
        
        // Checking existence
        boolean hasApple = hashSet.contains("Apple");
        boolean hasMango = hashSet.contains("Mango");
        
        System.out.println("Contains Apple: " + hasApple);
        System.out.println("Contains Mango: " + hasMango);
        
        // Removing elements
        hashSet.remove("Banana");
        System.out.println("After removal: " + hashSet);
        
        // Iterating through set
        System.out.println("Iterating with for-each:");
        for (String fruit : hashSet) {
            System.out.println(fruit);
        }
        
        // Set operations with another set
        Set<String> otherSet = new HashSet<>();
        otherSet.add("Orange");
        otherSet.add("Mango");
        otherSet.add("Grapes");
        
        // Union
        Set<String> union = new HashSet<>(hashSet);
        union.addAll(otherSet);
        System.out.println("Union: " + union);
        
        // Intersection
        Set<String> intersection = new HashSet<>(hashSet);
        intersection.retainAll(otherSet);
        System.out.println("Intersection: " + intersection);
        
        // Difference
        Set<String> difference = new HashSet<>(hashSet);
        difference.removeAll(otherSet);
        System.out.println("Difference: " + difference);
    }
}

TreeSet & NavigableSet Operations

import java.util.*;

public class TreeSetExample {
    public static void main(String[] args) {
        // TreeSet with natural ordering
        TreeSet<Integer> treeSet = new TreeSet<>();
        
        treeSet.add(10);
        treeSet.add(5);
        treeSet.add(15);
        treeSet.add(3);
        treeSet.add(7);
        
        System.out.println("TreeSet: " + treeSet); // Sorted automatically
        
        // NavigableSet operations
        System.out.println("First: " + treeSet.first());
        System.out.println("Last: " + treeSet.last());
        System.out.println("Lower than 7: " + treeSet.lower(7));
        System.out.println("Higher than 7: " + treeSet.higher(7));
        System.out.println("Floor of 6: " + treeSet.floor(6));
        System.out.println("Ceiling of 6: " + treeSet.ceiling(6));
        
        // Subset operations
        System.out.println("HeadSet up to 7: " + treeSet.headSet(7));
        System.out.println("TailSet from 7: " + treeSet.tailSet(7));
        System.out.println("Subset between 5 and 10: " + treeSet.subSet(5, 10));
        
        // Polling operations
        System.out.println("Poll first: " + treeSet.pollFirst());
        System.out.println("Poll last: " + treeSet.pollLast());
        System.out.println("After polling: " + treeSet);
        
        // TreeSet with custom comparator
        TreeSet<String> customTreeSet = new TreeSet<>(
            (s1, s2) -> s2.compareTo(s1) // Reverse order
        );
        
        customTreeSet.add("Apple");
        customTreeSet.add("Banana");
        customTreeSet.add("Orange");
        
        System.out.println("Custom sorted TreeSet: " + customTreeSet);
    }
}

Set Implementation Guidelines

  • Use HashSet for best performance, no ordering needed
  • Use LinkedHashSet when you need insertion order
  • Use TreeSet when you need sorted elements
  • Remember: Elements in HashSet/LinkedHashSet must implement equals() and hashCode()

Map Interface

The Map interface represents a collection of key-value pairs. Each key maps to exactly one value, and keys are unique.

Map Implementations

HashMap

Hash table implementation

Map

Most commonly used Map. No ordering guarantees. Allows one null key and multiple null values.

Get/Put: O(1)
Remove: O(1)
Contains Key: O(1)
Iteration: O(n)

LinkedHashMap

Hash table + linked list

Map

Maintains insertion order or access order. Slightly slower than HashMap.

Get/Put: O(1)
Remove: O(1)
Contains Key: O(1)
Iteration: O(n)

TreeMap

Red-Black tree implementation

SortedMap

Keys are sorted. Implements NavigableMap for navigation methods. No null keys allowed.

Get/Put: O(log n)
Remove: O(log n)
Contains Key: O(log n)
Iteration: O(n)

Map Operations & Examples

Basic Map Operations

import java.util.*;

public class MapExamples {
    public static void main(String[] args) {
        // HashMap example
        Map<String, Integer> hashMap = new HashMap<>();
        
        // Adding key-value pairs
        hashMap.put("Apple", 10);
        hashMap.put("Banana", 5);
        hashMap.put("Orange", 8);
        hashMap.put("Apple", 15); // Overwrites previous value
        
        System.out.println("HashMap: " + hashMap);
        
        // Accessing values
        Integer appleCount = hashMap.get("Apple");
        Integer mangoCount = hashMap.get("Mango"); // Returns null
        
        System.out.println("Apple count: " + appleCount);
        System.out.println("Mango count: " + mangoCount);
        
        // Safe access with getOrDefault
        Integer safeMangoCount = hashMap.getOrDefault("Mango", 0);
        System.out.println("Safe mango count: " + safeMangoCount);
        
        // Checking existence
        boolean hasApple = hashMap.containsKey("Apple");
        boolean hasCount5 = hashMap.containsValue(5);
        
        System.out.println("Has Apple key: " + hasApple);
        System.out.println("Has value 5: " + hasCount5);
        
        // Removing entries
        hashMap.remove("Banana");
        Integer removed = hashMap.remove("Orange", 8); // Remove if value matches
        
        System.out.println("After removal: " + hashMap);
        System.out.println("Removed Orange: " + removed);
        
        // Iterating through map
        System.out.println("Iterating key-value pairs:");
        for (Map.Entry<String, Integer> entry : hashMap.entrySet()) {
            System.out.println(entry.getKey() + " = " + entry.getValue());
        }
        
        System.out.println("Iterating keys:");
        for (String key : hashMap.keySet()) {
            System.out.println("Key: " + key);
        }
        
        System.out.println("Iterating values:");
        for (Integer value : hashMap.values()) {
            System.out.println("Value: " + value);
        }
        
        // Map operations with compute methods
        hashMap.compute("Apple", (k, v) -> v + 5); // Add 5 to Apple
        hashMap.computeIfAbsent("Mango", k -> 20); // Add if absent
        hashMap.computeIfPresent("Orange", (k, v) -> v * 2); // Double if present
        
        System.out.println("After compute operations: " + hashMap);
    }
}

TreeMap & NavigableMap Operations

import java.util.*;

public class TreeMapExample {
    public static void main(String[] args) {
        // TreeMap with natural ordering of keys
        TreeMap<Integer, String> treeMap = new TreeMap<>();
        
        treeMap.put(10, "Ten");
        treeMap.put(5, "Five");
        treeMap.put(15, "Fifteen");
        treeMap.put(3, "Three");
        treeMap.put(7, "Seven");
        
        System.out.println("TreeMap: " + treeMap); // Keys are sorted
        
        // NavigableMap operations
        System.out.println("First key: " + treeMap.firstKey());
        System.out.println("Last key: " + treeMap.lastKey());
        System.out.println("Lower key than 7: " + treeMap.lowerKey(7));
        System.out.println("Higher key than 7: " + treeMap.higherKey(7));
        System.out.println("Floor key of 6: " + treeMap.floorKey(6));
        System.out.println("Ceiling key of 6: " + treeMap.ceilingKey(6));
        
        // Submap operations
        System.out.println("HeadMap up to 7: " + treeMap.headMap(7));
        System.out.println("TailMap from 7: " + treeMap.tailMap(7));
        System.out.println("SubMap between 5 and 10: " + treeMap.subMap(5, 10));
        
        // Polling operations
        Map.Entry<Integer, String> firstEntry = treeMap.pollFirstEntry();
        Map.Entry<Integer, String> lastEntry = treeMap.pollLastEntry();
        
        System.out.println("Polled first: " + firstEntry);
        System.out.println("Polled last: " + lastEntry);
        System.out.println("After polling: " + treeMap);
        
        // TreeMap with custom comparator
        TreeMap<String, Integer> customTreeMap = new TreeMap<>(
            (s1, s2) -> s2.compareTo(s1) // Reverse order
        );
        
        customTreeMap.put("Apple", 10);
        customTreeMap.put("Banana", 5);
        customTreeMap.put("Orange", 8);
        
        System.out.println("Custom sorted TreeMap: " + customTreeMap);
        
        // Using comparator
        Comparator<? super String> comparator = customTreeMap.comparator();
        System.out.println("Comparator: " + comparator);
    }
}

Map Implementation Guidelines

  • Use HashMap for best performance, no ordering needed
  • Use LinkedHashMap when you need insertion/access order
  • Use TreeMap when you need sorted keys
  • Remember: Keys in HashMap/LinkedHashMap must implement equals() and hashCode()
