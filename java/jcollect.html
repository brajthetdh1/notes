Introduction to Collectors

Collectors are implementations of the Collector interface that implement various useful reduction operations, such as accumulating elements into collections, summarizing elements according to various criteria, etc.

Key Point: Collectors are used with the Stream.collect() method to transform streams into different data structures. 

                    
// Basic collector usage pattern
List<String> result = stream
    .collect(Collectors.toList());

Basic Collection Collectors

toList() Collector

Method Signature

public static <T> Collector<T, ?, List<T>> toList()

Explanation

  • Collects elements into a List<T>
  • Preserves encounter order
  • Allows duplicate elements
  • Returns implementation-specific List (usually ArrayList)

Examples

                            
// Example 1: Basic toList
List<String> names = Arrays.asList("John", "Jane", "Bob");
List<String> result = names.stream()
    .collect(Collectors.toList());

// Example 2: Filter and collect
List<String> longNames = names.stream()
    .filter(name -> name.length() > 3)
    .collect(Collectors.toList());

// Example 3: Map and collect
List<Integer> nameLengths = names.stream()
    .map(String::length)
    .collect(Collectors.toList());

toSet() Collector

Method Signature

public static <T> Collector<T, ?, Set<T>> toSet()

Explanation

  • Collects elements into a Set<T>
  • Removes duplicate elements
  • Does not preserve order
  • Returns implementation-specific Set (usually HashSet)

Examples

                            
// Example 1: Remove duplicates
List<String> names = Arrays.asList("John", "Jane", "Bob", "John");
Set<String> uniqueNames = names.stream()
    .collect(Collectors.toSet());
// Result: [John, Jane, Bob] (order may vary)

// Example 2: Filter and collect to set
Set<String> uniqueLongNames = names.stream()
    .filter(name -> name.length() > 3)
    .collect(Collectors.toSet());

// Example 3: Map to uppercase and collect
Set<String> upperNames = names.stream()
    .map(String::toUpperCase)
    .collect(Collectors.toSet());

toMap() Collector

Method Signatures

                            
// Basic toMap
public static <T, K, U> Collector<T, ?, Map<K, U>> toMap(
    Function<? super T, ? extends K> keyMapper,
    Function<? super T, ? extends U> valueMapper)

// With merge function
public static <T, K, U> Collector<T, ?, Map<K, U>> toMap(
    Function<? super T, ? extends K> keyMapper,
    Function<? super T, ? extends U> valueMapper,
    BinaryOperator<U> mergeFunction)

// With merge function and map supplier
public static <T, K, U, M extends Map<K, U>> Collector<T, ?, M> toMap(
    Function<? super T, ? extends K> keyMapper,
    Function<? super T, ? extends U> valueMapper,
    BinaryOperator<U> mergeFunction,
    Supplier<M> mapSupplier)

Examples

                            
class Person {
    String name; int age;
    // constructor, getters
}

List<Person> people = Arrays.asList(
    new Person("John", 25),
    new Person("Jane", 30)
);

// Example 1: Basic toMap
Map<String, Integer> nameToAge = people.stream()
    .collect(Collectors.toMap(
        Person::getName,    // key mapper
        Person::getAge      // value mapper
    ));

// Example 2: With merge function (handle duplicates)
Map<String, Integer> merged = people.stream()
    .collect(Collectors.toMap(
        Person::getName,
        Person::getAge,
        (oldAge, newAge) -> oldAge + newAge  // sum ages for duplicates
    ));

// Example 3: With custom map type
Map<String, Integer> linkedMap = people.stream()
    .collect(Collectors.toMap(
        Person::getName,
        Person::getAge,
        (oldVal, newVal) -> newVal,
        LinkedHashMap::new  // preserve insertion order
    ));

Grouping Collectors

groupingBy() Collector

Method Signatures

                            
// Simple grouping
public static <T, K> Collector<T, ?, Map<K, List<T>>> groupingBy(
    Function<? super T, ? extends K> classifier)

// With downstream collector
public static <T, K, A, D> Collector<T, ?, Map<K, D>> groupingBy(
    Function<? super T, ? extends K> classifier,
    Collector<? super T, A, D> downstream)

// With map factory and downstream
public static <T, K, D, A, M extends Map<K, D>> Collector<T, ?, M> groupingBy(
    Function<? super T, ? extends K> classifier,
    Supplier<M> mapFactory,
    Collector<? super T, A, D> downstream)

Classifier Function

A Function<T, K> that determines the group key for each element.

  • Input: Element of type T
  • Output: Classification key of type K
  • Purpose: Determine which group an element belongs to

Examples

                            
List<Person> people = Arrays.asList(
    new Person("John", 25, "IT"),
    new Person("Jane", 30, "HR"),
    new Person("Bob", 25, "IT")
);

// Example 1: Simple grouping by department
Map<String, List<Person>> byDept = people.stream()
    .collect(Collectors.groupingBy(Person::getDepartment));
// Result: {IT=[John, Bob], HR=[Jane]}

// Example 2: Grouping with counting
Map<String, Long> countByDept = people.stream()
    .collect(Collectors.groupingBy(
        Person::getDepartment,
        Collectors.counting()
    ));
// Result: {IT=2, HR=1}

// Example 3: Grouping with mapping and custom map
Map<String, Set<String>> namesByDept = people.stream()
    .collect(Collectors.groupingBy(
        Person::getDepartment,
        TreeMap::new,  // sorted keys
        Collectors.mapping(Person::getName, Collectors.toSet())
    ));
// Result: {HR=[Jane], IT=[Bob, John]} (alphabetically sorted)

Statistical Collectors

counting()

public static <T> Collector<T, ?, Long> counting()

Examples

                        
List<String> names = Arrays.asList("John", "Jane", "Bob");

// Count all elements
Long count = names.stream()
    .collect(Collectors.counting());
// Result: 3

// Count with grouping
Map<String, Long> countByDept = people.stream()
    .collect(Collectors.groupingBy(
        Person::getDepartment,
        Collectors.counting()
    ));

summingInt() / averagingDouble()

                        
public static <T> Collector<T, ?, Integer> summingInt(
    ToIntFunction<? super T> mapper)

public static <T> Collector<T, ?, Double> averagingDouble(
    ToDoubleFunction<? super T> mapper)

Examples

                        
// Sum all salaries
Integer totalSalary = people.stream()
    .collect(Collectors.summingInt(Person::getSalary));

// Average age
Double avgAge = people.stream()
    .collect(Collectors.averagingDouble(Person::getAge));

// Summary statistics
DoubleSummaryStatistics stats = people.stream()
    .collect(Collectors.summarizingDouble(Person::getSalary));
// Provides count, sum, min, max, average

Joining Collectors

joining() Collector

Method Signatures

                            
// Simple joining
public static Collector<CharSequence, ?, String> joining()

// With delimiter
public static Collector<CharSequence, ?, String> joining(
    CharSequence delimiter)

// With delimiter, prefix and suffix
public static Collector<CharSequence, ?, String> joining(
    CharSequence delimiter, 
    CharSequence prefix, 
    CharSequence suffix)

Examples

                            
List<String> names = Arrays.asList("John", "Jane", "Bob");

// Simple join
String joined = names.stream()
    .collect(Collectors.joining());
// Result: "JohnJaneBob"

// Join with delimiter
String delimited = names.stream()
    .collect(Collectors.joining(", "));
// Result: "John, Jane, Bob"

// Join with prefix and suffix
String formatted = names.stream()
    .collect(Collectors.joining(", ", "People: ", "!"));
// Result: "People: John, Jane, Bob!"

// In grouping
Map<String, String> namesByDept = people.stream()
    .collect(Collectors.groupingBy(
        Person::getDepartment,
        Collectors.mapping(
            Person::getName,
            Collectors.joining(", ")
        )
    ));

Collector Parameters Guide

Parameter Type Purpose Example
Classifier Function<T, K> Determine group key for elements Person::getDepartment
Mapper Function<T, U> Transform elements before collecting Person::getName
Downstream Collector<T, A, R> Further processing on grouped data Collectors.counting()
Predicate Predicate<T> Filter or partition elements p -> p.getAge() > 30
BinaryOperator BinaryOperator<T> Merge or reduce elements (a, b) -> a + b
Supplier Supplier<M> Provide collection instances LinkedHashMap::new

Quick Reference

Basic Collection

  • toList() - Collect to List
  • toSet() - Collect to Set
  • toMap() - Collect to Map
  • toCollection() - Custom collection

Grouping

  • groupingBy() - Group elements
  • partitioningBy() - Partition by predicate

Statistical

  • counting() - Count elements
  • summingInt() - Sum values
  • averagingDouble() - Average values
  • summarizingInt() - Full statistics

Joining

  • joining() - Concatenate strings
  • joining(delimiter) - With separator
  • joining(delimiter, prefix, suffix) - Formatted

Advanced

  • mapping() - Transform before collect
  • filtering() - Filter before collect
  • reducing() - Custom reduction
  • collectingAndThen() - Post-processing

Best Practices

  • Use method references when possible
  • Handle duplicate keys in toMap
  • Combine collectors for complex operations
  • Use primitive collectors for performance
