Introduction to Java Streams

What are Streams?

Java Streams are a powerful feature introduced in Java 8 that allows functional-style operations on sequences of elements. Streams provide a declarative way to process collections of data.

Key Concept: Streams are not data structures - they take input from collections, arrays, or I/O channels and provide a pipeline for data processing.

Stream Characteristics:

  • Not a data structure - Doesn't store elements
  • Functional in nature - Doesn't modify source data
  • Lazy execution - Intermediate operations are lazy
  • Potentially unbounded - Can work with infinite sequences
  • Consumable - Elements are visited only once

Basic Stream Pipeline

                            
List<String> names = Arrays.asList("John", "Jane", "Bob", "Alice");

// Stream pipeline example
List<String> result = names.stream()          // Source
    .filter(name -> name.startsWith("J"))     // Intermediate operation
    .map(String::toUpperCase)                 // Intermediate operation  
    .sorted()                                 // Intermediate operation
    .collect(Collectors.toList());            // Terminal operation

// Result: ["JANE", "JOHN"]

Pipeline Components:

  1. Source - Where data comes from
  2. Intermediate Operations - Transform the stream
  3. Terminal Operation - Produce result or side-effect

Intermediate Operations

Intermediate operations transform a stream into another stream. They are lazy - execution doesn't start until a terminal operation is invoked.

filter()

Method Signature

                                
Stream<T> filter(Predicate<? super T> predicate)

Purpose: Filters elements based on a predicate

Predicate: Function that takes an element and returns boolean

Examples

                                
List<String> names = Arrays.asList("John", "Jane", "Bob", "Alice", "Tom");

// Filter names starting with 'J'
List<String> jNames = names.stream()
    .filter(name -> name.startsWith("J"))
    .collect(Collectors.toList());
// Result: ["John", "Jane"]

// Filter with multiple conditions
List<String> longJNames = names.stream()
    .filter(name -> name.startsWith("J") && name.length() > 3)
    .collect(Collectors.toList());
// Result: ["John", "Jane"]

// Filter with method reference
List<String> nonEmpty = names.stream()
    .filter(Objects::nonNull)
    .filter(name -> !name.isEmpty())
    .collect(Collectors.toList());

map()

Method Signature

                                
<R> Stream<R> map(Function<? super T, ? extends R> mapper)

Purpose: Transforms each element using the given function

Function: Takes an element of type T, returns element of type R

Examples

                                
List<String> names = Arrays.asList("John", "Jane", "Bob");

// Transform to uppercase
List<String> upperNames = names.stream()
    .map(String::toUpperCase)
    .collect(Collectors.toList());
// Result: ["JOHN", "JANE", "BOB"]

// Transform to lengths
List<Integer> nameLengths = names.stream()
    .map(String::length)
    .collect(Collectors.toList());
// Result: [4, 4, 3]

// Complex transformation
List<String> formatted = names.stream()
    .map(name -> "Name: " + name + " (Length: " + name.length() + ")")
    .collect(Collectors.toList());

flatMap()

Method Signature

                                
<R> Stream<R> flatMap(Function<? super T, ? extends Stream<? extends R>> mapper)

Purpose: Flattens nested structures into a single stream

Use Case: When each element maps to multiple elements

Examples

                                
List<List<String>> nestedList = Arrays.asList(
    Arrays.asList("a", "b", "c"),
    Arrays.asList("d", "e"),
    Arrays.asList("f", "g", "h")
);

// Flatten nested lists
List<String> flatList = nestedList.stream()
    .flatMap(List::stream)
    .collect(Collectors.toList());
// Result: ["a", "b", "c", "d", "e", "f", "g", "h"]

// Split strings into characters
List<String> words = Arrays.asList("hello", "world");
List<String> chars = words.stream()
    .flatMap(word -> Arrays.stream(word.split("")))
    .collect(Collectors.toList());
// Result: ["h","e","l","l","o","w","o","r","l","d"]

sorted()

Method Signatures

                                
Stream<T> sorted()                          // Natural order
Stream<T> sorted(Comparator<? super T> comparator)  // Custom order

Purpose: Returns a stream with elements sorted

Note: For infinite streams, sorted() will never return!

Examples

                                
List<String> names = Arrays.asList("John", "Alice", "Bob", "Jane");

// Natural order
List<String> naturalSorted = names.stream()
    .sorted()
    .collect(Collectors.toList());
// Result: ["Alice", "Bob", "Jane", "John"]

// Reverse order
List<String> reverseSorted = names.stream()
    .sorted(Comparator.reverseOrder())
    .collect(Collectors.toList());
// Result: ["John", "Jane", "Bob", "Alice"]

// Custom comparator
List<String> lengthSorted = names.stream()
    .sorted(Comparator.comparingInt(String::length))
    .collect(Collectors.toList());
// Result: ["Bob", "John", "Jane", "Alice"] (by length)

// Multiple criteria
List<String> complexSorted = names.stream()
    .sorted(Comparator
        .comparingInt(String::length)
        .thenComparing(Comparator.naturalOrder()))
    .collect(Collectors.toList());

distinct()

Method Signature

                                
Stream<T> distinct()

Purpose: Returns a stream with duplicate elements removed

Uses equals() method for object comparison

Examples

                                
List<Integer> numbers = Arrays.asList(1, 2, 2, 3, 4, 4, 4, 5);

// Remove duplicates
List<Integer> unique = numbers.stream()
    .distinct()
    .collect(Collectors.toList());
// Result: [1, 2, 3, 4, 5]

// With objects
List<Person> people = Arrays.asList(
    new Person("John", 25),
    new Person("Jane", 30),
    new Person("John", 25)  // duplicate
);

List<Person> uniquePeople = people.stream()
    .distinct()
    .collect(Collectors.toList());
// Result: Only unique Person objects (based on equals())

limit()

                            
Stream<T> limit(long maxSize)

Truncates the stream to be no longer than maxSize

                            
Stream.iterate(1, n -> n + 1)
    .limit(5)
    .forEach(System.out::println);
// Output: 1 2 3 4 5

skip()

                            
Stream<T> skip(long n)

Discards the first n elements of the stream

                            
IntStream.range(1, 10)
    .skip(5)
    .forEach(System.out::println);
// Output: 6 7 8 9

peek()

Method Signature

                                
Stream<T> peek(Consumer<? super T> action)

Purpose: Performs an action on each element as it's consumed

Warning: Mainly for debugging - don't use for mutation in production!

Examples

                                
List<String> result = Stream.of("a", "b", "c")
    .peek(System.out::println)  // Debug: see elements as they flow
    .map(String::toUpperCase)
    .peek(s -> System.out.println("After map: " + s))
    .collect(Collectors.toList());

// Output:
// a
// After map: A
// b  
// After map: B
// c
// After map: C

// Logging transformations
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
List<Integer> doubled = numbers.stream()
    .peek(n -> System.out.println("Processing: " + n))
    .map(n -> n * 2)
    .peek(n -> System.out.println("Doubled: " + n))
    .collect(Collectors.toList());

Terminal Operations

Terminal operations produce a result or side-effect. When a terminal operation is invoked, the stream pipeline is executed and the stream can no longer be used.

forEach()

Method Signature

                                
void forEach(Consumer<? super T> action)

Purpose: Performs an action for each element

Note: Order not guaranteed in parallel streams

Examples

                                
List<String> names = Arrays.asList("John", "Jane", "Bob");

// Simple iteration
names.stream().forEach(System.out::println);

// With external collection
List<String> result = new ArrayList<>();
names.stream()
    .map(String::toUpperCase)
    .forEach(result::add);

// Complex action
names.stream().forEach(name -> {
    System.out.println("Processing: " + name);
    // Additional processing...
});

// forEachOrdered for parallel streams
names.parallelStream()
    .forEachOrdered(System.out::println); // Maintains order

collect()

Method Signatures

                                
<R> R collect(Collector<? super T, A, R> collector)
<R> R collect(Supplier<R> supplier,
              BiConsumer<R, ? super T> accumulator,
              BiConsumer<R, R> combiner)

Purpose: Performs mutable reduction on elements

Most powerful terminal operation - see Collectors guide for details

Examples

                                
List<String> names = Arrays.asList("John", "Jane", "Bob");

// Using Collectors
List<String> list = names.stream().collect(Collectors.toList());
Set<String> set = names.stream().collect(Collectors.toSet());
String joined = names.stream().collect(Collectors.joining(", "));

// Custom collection
TreeSet<String> sortedSet = names.stream()
    .collect(Collectors.toCollection(TreeSet::new));

// Manual collect
List<String> manual = names.stream().collect(
    ArrayList::new,      // supplier
    ArrayList::add,      // accumulator  
    ArrayList::addAll    // combiner (for parallel)
);

// Complex collection
Map<String, Integer> nameLengthMap = names.stream()
    .collect(Collectors.toMap(
        Function.identity(),
        String::length
    ));

Reduction Operations

reduce()

                                
Optional<T> reduce(BinaryOperator<T> accumulator)
T reduce(T identity, BinaryOperator<T> accumulator)
<U> U reduce(U identity,
            BiFunction<U,? super T,U> accumulator,
            BinaryOperator<U> combiner)
                                
                            
                                
// Sum numbers
Optional<Integer> sum = Stream.of(1,2,3)
    .reduce(Integer::sum);

// With identity
Integer total = Stream.of(1,2,3)
    .reduce(0, Integer::sum);

min() / max()

                                
Optional<T> min(Comparator<? super T> comparator)
Optional<T> max(Comparator<? super T> comparator)
                                
                            
                                
Optional<String> min = Stream.of("a","bb","ccc")
    .min(Comparator.comparingInt(String::length));

Optional<String> max = Stream.of("a","bb","ccc")  
    .max(Comparator.naturalOrder());

count()

                                
long count()
                                
                            
                                
long count = Stream.of(1,2,3,4,5).count();

long evenCount = Stream.of(1,2,3,4,5)
    .filter(n -> n % 2 == 0)
    .count();

Matching Operations

anyMatch()

Returns true if any element matches

                                
boolean hasEven = Stream.of(1,2,3)
    .anyMatch(n -> n % 2 == 0); // true

allMatch()

Returns true if all elements match

                                
boolean allPositive = Stream.of(1,2,3)
    .allMatch(n -> n > 0); // true

noneMatch()

Returns true if no elements match

                                
boolean noNegative = Stream.of(1,2,3)
    .noneMatch(n -> n < 0); // true

Finding Operations

findFirst()

                                
Optional<T> findFirst()

Returns first element (respects encounter order)

                                
Optional<String> first = Stream.of("a","b","c")
    .findFirst(); // "a"

Optional<String> firstLong = Stream.of("a","bb","ccc")
    .filter(s -> s.length() > 1)
    .findFirst(); // "bb"

findAny()

                                
Optional<T> findAny()

Returns any element (better for parallel streams)

                                
Optional<String> any = Stream.of("a","b","c")
    .findAny(); // could be "a", "b", or "c"

// More efficient in parallel
Optional<String> anyLong = Stream.of("a","bb","ccc")
    .parallel()
    .filter(s -> s.length() > 1)
    .findAny();

Parallel Streams

Creating Parallel Streams

                                
// From collections
List<String> list = Arrays.asList("a", "b", "c");
Stream<String> parallel1 = list.parallelStream();

// Convert sequential to parallel
Stream<String> parallel2 = list.stream().parallel();

// Parallel array stream
IntStream parallelInt = Arrays.stream(new int[100])
    .parallel();
When to Use Parallel Streams:
  • Large datasets
  • CPU-intensive operations
  • No shared mutable state
  • Order doesn't matter

Examples & Considerations

                                
// Good for parallel - stateless operations
long count = list.parallelStream()
    .filter(s -> s.length() > 3)
    .count();

// Bad for parallel - stateful operations
List<String> result = new ArrayList<>();
list.parallelStream()
    .forEach(result::add); // Race condition!

// Use collect instead for parallel
List<String> safeResult = list.parallelStream()
    .collect(Collectors.toList());

// Measure performance
long start = System.currentTimeMillis();
list.parallelStream()
    .map(String::toUpperCase)
    .collect(Collectors.toList());
long time = System.currentTimeMillis() - start;

Infinite Streams

Creating Infinite Streams

                                
// Generate with supplier
Stream<Double> randoms = Stream.generate(Math::random);
Stream<String> constants = Stream.generate(() -> "hello");

// Iterate with seed and function
Stream<Integer> numbers = Stream.iterate(0, n -> n + 1);
Stream<Integer> powers = Stream.iterate(1, n -> n * 2);

// Finite from infinite (must use limit!)
List<Integer> first10 = Stream.iterate(0, n -> n + 1)
    .limit(10)
    .collect(Collectors.toList());

Practical Examples

                                
// Fibonacci sequence
Stream.iterate(new long[]{0, 1}, 
        fib -> new long[]{fib[1], fib[0] + fib[1]})
    .limit(10)
    .map(fib -> fib[0])
    .forEach(System.out::println);

// Random data generation
List<String> randomNames = Stream.generate(() -> 
        "User" + (int)(Math.random() * 1000))
    .limit(5)
    .collect(Collectors.toList());

// Polling simulation
Stream.iterate(0, i -> i + 1)
    .peek(i -> {
        try { Thread.sleep(1000); } 
        catch (InterruptedException e) {}
    })
    .limit(5)
    .forEach(i -> System.out.println("Polling..."));

Best Practices & Common Pitfalls

✅ Best Practices

Use Method References

                                
// ✅ Good
list.stream().map(String::toUpperCase)

// ❌ Avoid  
list.stream().map(s -> s.toUpperCase())

Use Primitive Streams for Performance

                                
// ✅ Good - no boxing overhead
IntStream.range(1, 1000).sum()

// ❌ Avoid - boxing overhead
Stream.iterate(1, n -> n + 1)
    .limit(1000)
    .reduce(0, Integer::sum)

Favor Immutability

                                
// ✅ Good - no side effects
List<String> result = input.stream()
    .filter(s -> s != null)
    .map(String::trim)
    .collect(Collectors.toList());

// ❌ Avoid - mutating external state
List<String> result = new ArrayList<>();
input.stream()
    .forEach(s -> result.add(s.trim())); // Side effect!

❌ Common Pitfalls

Reusing Streams

                                
Stream<String> stream = list.stream();

// ✅ First usage
stream.filter(s -> s.length() > 3).count();

// ❌ IllegalStateException - stream already used
stream.map(String::toUpperCase).count();

Modifying Source Collection

                                
List<String> list = new ArrayList<>(Arrays.asList("a", "b", "c"));

list.stream()
    .peek(s -> {
        if ("b".equals(s)) {
            list.remove(s); // ❌ ConcurrentModificationException
        }
    })
    .forEach(System.out::println);

Infinite Streams Without Limit

                                
// ❌ Never completes - infinite stream
Stream.iterate(0, n -> n + 1)
    .forEach(System.out::println);

// ✅ Always use limit with infinite streams
Stream.iterate(0, n -> n + 1)
    .limit(100)
    .forEach(System.out::println);

🚀 Performance Tips

Operation Order Matters

                                
// ✅ Better performance - filter first
List<String> result = list.stream()
    .filter(s -> s.length() > 10)  // Reduce early
    .map(String::toUpperCase)      // Then transform
    .collect(Collectors.toList());

// ❌ Worse performance - transform first  
List<String> result = list.stream()
    .map(String::toUpperCase)      // Transform all
    .filter(s -> s.length() > 10)  // Then filter
    .collect(Collectors.toList());

Avoid Boxing Overhead

                                
// ✅ Use primitive streams
IntSummaryStatistics stats = people.stream()
    .mapToInt(Person::getAge)
    .summaryStatistics();

// ❌ Boxing overhead
Double average = people.stream()
    .map(Person::getAge)
    .collect(Collectors.averagingInt(Integer::intValue));
