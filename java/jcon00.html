What is a Thread?

A thread in Java is a lightweight sub-process that allows a program to operate more efficiently by performing multiple tasks simultaneously. Threads share the same memory space, making communication between threads faster than separate processes.

Key Points

  • Threads are independent execution paths within a program
  • Each thread has its own call stack but shares heap memory
  • Java provides built-in support for multithreading
  • Threads can run concurrently on multi-core systems

Thread vs Process

Process

Heavyweight, separate memory space

Thread

Lightweight, shared memory space

Creating Threads in Java

Extending Thread Class

Create a thread by extending the Thread class and overriding the run() method.

// Step 1: Extend Thread class
class MyThread extends Thread {
    // Step 2: Override run() method
    public void run() {
        for (int i = 1; i <= 5; i++) {
            System.out.println(Thread.currentThread().getName() + 
                " - Count: " + i);
            try {
                Thread.sleep(500); // Pause for 500ms
            } catch (InterruptedException e) {
                System.out.println("Thread interrupted");
            }
        }
    }
}

public class ThreadExample {
    public static void main(String[] args) {
        // Step 3: Create thread objects
        MyThread t1 = new MyThread();
        MyThread t2 = new MyThread();
        
        // Step 4: Start threads (calls run() method)
        t1.start();
        t2.start();
        
        System.out.println("Main thread continues execution");
    }
}

Note

Always call start() method, not run() directly. start() creates a new thread while run() executes in the current thread.

Implementing Runnable Interface

Create a thread by implementing the Runnable interface and passing it to a Thread object.

// Step 1: Implement Runnable interface
class MyRunnable implements Runnable {
    // Step 2: Implement run() method
    public void run() {
        for (int i = 1; i <= 5; i++) {
            System.out.println(Thread.currentThread().getName() + 
                " - Count: " + i);
            try {
                Thread.sleep(500); // Pause for 500ms
            } catch (InterruptedException e) {
                System.out.println("Thread interrupted");
            }
        }
    }
}

public class RunnableExample {
    public static void main(String[] args) {
        // Step 3: Create Runnable object
        MyRunnable myRunnable = new MyRunnable();
        
        // Step 4: Create Thread objects with Runnable
        Thread t1 = new Thread(myRunnable, "Thread-1");
        Thread t2 = new Thread(myRunnable, "Thread-2");
        
        // Step 5: Start threads
        t1.start();
        t2.start();
        
        System.out.println("Main thread continues execution");
    }
}

Advantage

This approach allows your class to extend another class since Java doesn't support multiple inheritance.

Using Lambda Expressions (Java 8+)

With Java 8+, you can create threads using lambda expressions for concise code.

public class LambdaThreadExample {
    public static void main(String[] args) {
        // Using lambda expression with Runnable
        Thread t1 = new Thread(() -> {
            for (int i = 1; i <= 5; i++) {
                System.out.println(Thread.currentThread().getName() + 
                    " - Count: " + i);
                try {
                    Thread.sleep(500);
                } catch (InterruptedException e) {
                    System.out.println("Thread interrupted");
                }
            }
        }, "Lambda-Thread");
        
        t1.start();
        
        // Even shorter with method reference
        Thread t2 = new Thread(LambdaThreadExample::printNumbers);
        t2.start();
        
        System.out.println("Main thread continues execution");
    }
    
    private static void printNumbers() {
        for (int i = 1; i <= 5; i++) {
            System.out.println(Thread.currentThread().getName() + 
                " - Count: " + i);
            try {
                Thread.sleep(500);
            } catch (InterruptedException e) {
                System.out.println("Thread interrupted");
            }
        }
    }
}

Thread Lifecycle & States

A thread in Java can be in one of several states during its lifecycle. Understanding these states is crucial for effective multithreading.

Thread State Transition Diagram

NEW

Thread created but not started

RUNNABLE

Ready to run or running

BLOCKED

Waiting for monitor lock

TERMINATED

Execution completed

WAITING

Waiting indefinitely for another thread

TIMED_WAITING

Waiting for a specified time

public class ThreadStateExample {
    public static void main(String[] args) throws InterruptedException {
        Thread thread = new Thread(() -> {
            try {
                Thread.sleep(2000); // TIMED_WAITING state
                synchronized(ThreadStateExample.class) {
                    // Could be BLOCKED if another thread holds the lock
                    System.out.println("Thread executing synchronized block");
                }
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        });
        
        System.out.println("After creation: " + thread.getState()); // NEW
        
        thread.start();
        System.out.println("After start: " + thread.getState()); // RUNNABLE
        
        Thread.sleep(100);
        System.out.println("After short sleep: " + thread.getState()); // TIMED_WAITING
        
        Thread.sleep(3000);
        System.out.println("After completion: " + thread.getState()); // TERMINATED
    }
}

Important Thread Methods

start()

Starts the thread and invokes the run() method. Creates a new call stack.

thread.start();

run()

Contains the code that constitutes the thread's task.

public void run() { // thread logic }

sleep(long millis)

Pauses the thread execution for specified milliseconds.

Thread.sleep(1000); // Sleep for 1 second

join()

Waits for this thread to die before continuing execution.

thread.join(); // Wait for thread to finish

interrupt()

Interrupts the thread, causing InterruptedException if sleeping/waiting.

thread.interrupt();

setPriority(int priority)

Sets thread priority (1=MIN to 10=MAX).

thread.setPriority(Thread.MAX_PRIORITY);

Thread Methods Example

public class ThreadMethodsExample {
    public static void main(String[] args) throws InterruptedException {
        Thread t1 = new Thread(() -> {
            System.out.println(Thread.currentThread().getName() + " started");
            try {
                // Sleep for 2 seconds
                Thread.sleep(2000);
            } catch (InterruptedException e) {
                System.out.println("Thread was interrupted during sleep");
                return;
            }
            System.out.println(Thread.currentThread().getName() + " completed");
        }, "Worker-Thread");
        
        // Set thread priority
        t1.setPriority(Thread.NORM_PRIORITY);
        
        // Start the thread
        t1.start();
        
        // Main thread continues execution
        System.out.println("Main thread doing some work...");
        Thread.sleep(500);
        
        // Check if thread is alive
        System.out.println("Is thread alive? " + t1.isAlive());
        
        // Wait for thread to complete (join with timeout)
        t1.join(3000);
        
        System.out.println("Is thread alive after join? " + t1.isAlive());
        System.out.println("Main thread completed");
    }
}

Thread Synchronization

Synchronization is needed to prevent thread interference and consistency problems when multiple threads access shared resources.

Without Synchronization

class Counter {
    private int count = 0;
    
    public void increment() {
        count++; // Not thread-safe
    }
    
    public int getCount() {
        return count;
    }
}

public class WithoutSyncExample {
    public static void main(String[] args) throws InterruptedException {
        Counter counter = new Counter();
        
        Thread t1 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) {
                counter.increment();
            }
        });
        
        Thread t2 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) {
                counter.increment();
            }
        });
        
        t1.start();
        t2.start();
        
        t1.join();
        t2.join();
        
        // May not print 2000 due to race condition
        System.out.println("Final count: " + counter.getCount());
    }
}

Problem

Race condition: The final count may be less than 2000 due to unsynchronized access.

With Synchronization

class SynchronizedCounter {
    private int count = 0;
    
    // Synchronized method
    public synchronized void increment() {
        count++; // Thread-safe
    }
    
    public int getCount() {
        return count;
    }
}

public class WithSyncExample {
    public static void main(String[] args) throws InterruptedException {
        SynchronizedCounter counter = new SynchronizedCounter();
        
        Thread t1 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) {
                counter.increment();
            }
        });
        
        Thread t2 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) {
                counter.increment();
            }
        });
        
        t1.start();
        t2.start();
        
        t1.join();
        t2.join();
        
        // Will always print 2000
        System.out.println("Final count: " + counter.getCount());
    }
}

Solution

Synchronized method ensures only one thread can execute it at a time.

Synchronized Block

Synchronized blocks provide more fine-grained control than synchronized methods.

class FineGrainedSync {
    private int count1 = 0;
    private int count2 = 0;
    private final Object lock1 = new Object();
    private final Object lock2 = new Object();
    
    public void increment1() {
        // Synchronized block with custom lock
        synchronized(lock1) {
            count1++;
        }
    }
    
    public void increment2() {
        // Synchronized block with different lock
        synchronized(lock2) {
            count2++;
        }
    }
    
    public void printCounts() {
        synchronized(lock1) {
            synchronized(lock2) {
                System.out.println("Count1: " + count1 + ", Count2: " + count2);
            }
        }
    }
}

public class SynchronizedBlockExample {
    public static void main(String[] args) {
        FineGrainedSync counter = new FineGrainedSync();
        
        Thread t1 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) {
                counter.increment1();
                counter.increment2();
            }
        });
        
        Thread t2 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) {
                counter.increment1();
                counter.increment2();
            }
        });
        
        t1.start();
        t2.start();
        
        try {
            t1.join();
            t2.join();
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        
        counter.printCounts(); // Both will be 2000
    }
}
