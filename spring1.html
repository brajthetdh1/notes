Spring Boot Actuator & Monitoring - Complete Guide

Spring Boot Actuator provides production-ready features to help you monitor and manage your application. It includes health checks, metrics, auditing, and more.

What You'll Learn
  • Setting up and configuring Actuator
  • Using built-in endpoints for monitoring
  • Creating custom health indicators and endpoints
  • Integrating with monitoring tools
  • Security best practices for Actuator
Key Features
  • Health monitoring and status checks
  • Application metrics collection
  • Environment and configuration inspection
  • Custom monitoring endpoints
  • Integration with Prometheus, Grafana, etc.
Tip: Actuator endpoints provide deep insight into your application's internals, making it easier to monitor and troubleshoot in production environments.

Getting Started with Actuator

1. Adding Actuator Dependency

<!-- Maven -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>

<!-- Gradle -->
implementation 'org.springframework.boot:spring-boot-starter-actuator'
2. Basic Configuration

# application.properties
# Enable all actuator endpoints (be careful in production!)
management.endpoints.web.exposure.include=*

# Or enable specific endpoints
management.endpoints.web.exposure.include=health,info,metrics,env

# Change actuator base path
management.endpoints.web.base-path=/manage

# Enable shutdown endpoint (disabled by default)
management.endpoint.shutdown.enabled=true

# Server port for actuator endpoints
management.server.port=8081
3. Testing Basic Endpoints

After starting your application, you can access:

Creating Custom Health Indicators

@Component
public class CustomServiceHealthIndicator implements HealthIndicator {
    
    private final CustomService customService;
    
    public CustomServiceHealthIndicator(CustomService customService) {
        this.customService = customService;
    }
    
    @Override
    public Health health() {
        try {
            // Check if your service is healthy
            boolean isHealthy = customService.isHealthy();
            
            if (isHealthy) {
                return Health.up()
                    .withDetail("service", "Custom Service")
                    .withDetail("status", "Available")
                    .withDetail("responseTime", customService.getResponseTime() + "ms")
                    .build();
            } else {
                return Health.down()
                    .withDetail("service", "Custom Service")
                    .withDetail("status", "Unavailable")
                    .withDetail("error", "Service not responding")
                    .build();
            }
        } catch (Exception e) {
            return Health.down(e)
                .withDetail("service", "Custom Service")
                .withDetail("error", e.getMessage())
                .build();
        }
    }
}

// Complex health indicator with multiple checks
@Component
public class DatabaseConnectivityHealthIndicator implements HealthIndicator {
    
    @Autowired
    private DataSource dataSource;
    
    @Override
    public Health health() {
        Health.Builder status = Health.up();
        
        try (Connection connection = dataSource.getConnection()) {
            // Check connection validity
            boolean isValid = connection.isValid(5);
            
            if (!isValid) {
                status = Health.down().withDetail("error", "Database connection invalid");
            }
            
            // Check if we can execute queries
            try (Statement stmt = connection.createStatement();
                 ResultSet rs = stmt.executeQuery("SELECT 1")) {
                
                if (rs.next()) {
                    status.withDetail("queryTest", "SUCCESS");
                }
            }
            
        } catch (SQLException e) {
            status = Health.down(e)
                .withDetail("database", "Connection failed")
                .withDetail("error", e.getMessage());
        }
        
        return status.build();
    }
}

Creating Custom Metrics

@Service
public class OrderService {
    
    private final MeterRegistry meterRegistry;
    private final Counter orderCounter;
    private final Timer orderProcessingTimer;
    private final DistributionSummary orderAmountSummary;
    private final Gauge activeOrdersGauge;
    private final AtomicInteger activeOrders = new AtomicInteger(0);
    
    public OrderService(MeterRegistry meterRegistry) {
        this.meterRegistry = meterRegistry;
        
        // Counter - for counting events
        this.orderCounter = Counter.builder("orders.total")
            .description("Total number of orders")
            .tag("service", "order-service")
            .register(meterRegistry);
            
        // Timer - for measuring duration
        this.orderProcessingTimer = Timer.builder("orders.processing.time")
            .description("Order processing time")
            .tag("service", "order-service")
            .register(meterRegistry);
            
        // DistributionSummary - for tracking value distributions
        this.orderAmountSummary = DistributionSummary.builder("orders.amount")
            .description("Order amount distribution")
            .baseUnit("USD")
            .register(meterRegistry);
            
        // Gauge - for measuring current value
        this.activeOrdersGauge = Gauge.builder("orders.active")
            .description("Number of active orders")
            .tag("service", "order-service")
            .register(meterRegistry, activeOrders);
    }
    
    public void processOrder(Order order) {
        // Start timing
        Timer.Sample sample = Timer.start(meterRegistry);
        
        try {
            activeOrders.incrementAndGet();
            
            // Business logic
            processOrderBusinessLogic(order);
            
            // Record metrics
            orderCounter.increment();
            orderAmountSummary.record(order.getAmount());
            
        } finally {
            // Stop timing and record
            sample.stop(orderProcessingTimer);
            activeOrders.decrementAndGet();
        }
    }
    
    @EventListener
    public void handleOrderEvent(OrderEvent event) {
        // Record event-based metrics
        meterRegistry.counter("orders.events",
            "type", event.getType(),
            "status", event.getStatus()
        ).increment();
    }
}

// Using @Timed annotation
@Service
public class ProductService {
    
    @Timed(value = "products.search.time", description = "Time taken to search products")
    public List searchProducts(String query) {
        // Search implementation
        return productRepository.findByQuery(query);
    }
    
    @Counted(value = "products.view.count", description = "Number of product views")
    public Product getProduct(Long id) {
        return productRepository.findById(id).orElse(null);
    }
}

Custom Info Contributors

@Component
public class CustomInfoContributor implements InfoContributor {
    
    @Value("${app.version}")
    private String appVersion;
    
    @Autowired
    private ApplicationContext context;
    
    @Override
    public void contribute(Info.Builder builder) {
        Map customInfo = new HashMap<>();
        customInfo.put("version", appVersion);
        customInfo.put("timestamp", Instant.now().toString());
        customInfo.put("activeProfiles", Arrays.toString(context.getEnvironment().getActiveProfiles()));
        customInfo.put("beanCount", context.getBeanDefinitionCount());
        
        builder.withDetail("custom", customInfo);
    }
}

@Component
public class SystemInfoContributor implements InfoContributor {
    
    @Override
    public void contribute(Info.Builder builder) {
        Runtime runtime = Runtime.getRuntime();
        
        Map systemInfo = new HashMap<>();
        systemInfo.put("availableProcessors", runtime.availableProcessors());
        systemInfo.put("freeMemory", runtime.freeMemory());
        systemInfo.put("maxMemory", runtime.maxMemory());
        systemInfo.put("totalMemory", runtime.totalMemory());
        systemInfo.put("systemLoadAverage", ManagementFactory.getOperatingSystemMXBean().getSystemLoadAverage());
        
        builder.withDetail("system", systemInfo);
    }
}

@Component
public class DatabaseInfoContributor implements InfoContributor {
    
    @Autowired
    private DataSource dataSource;
    
    @Override
    public void contribute(Info.Builder builder) {
        try (Connection connection = dataSource.getConnection()) {
            DatabaseMetaData metaData = connection.getMetaData();
            
            Map dbInfo = new HashMap<>();
            dbInfo.put("databaseProductName", metaData.getDatabaseProductName());
            dbInfo.put("databaseProductVersion", metaData.getDatabaseProductVersion());
            dbInfo.put("driverName", metaData.getDriverName());
            dbInfo.put("driverVersion", metaData.getDriverVersion());
            dbInfo.put("url", metaData.getURL());
            
            builder.withDetail("database", dbInfo);
        } catch (SQLException e) {
            builder.withDetail("databaseError", e.getMessage());
        }
    }
}

Custom Endpoints

You can create custom actuator endpoints to expose application-specific information and operations.

Creating Custom Read-only Endpoint

@Component
@Endpoint(id = "features")
public class FeaturesEndpoint {
    
    private final FeatureService featureService;
    
    public FeaturesEndpoint(FeatureService featureService) {
        this.featureService = featureService;
    }
    
    @ReadOperation
    public Map features() {
        Map features = new HashMap<>();
        features.put("totalFeatures", featureService.getTotalFeatures());
        features.put("enabledFeatures", featureService.getEnabledFeatures());
        features.put("disabledFeatures", featureService.getDisabledFeatures());
        features.put("lastUpdated", Instant.now().toString());
        return features;
    }
    
    @ReadOperation
    public FeatureStatus featureStatus(@Selector String featureName) {
        return featureService.getFeatureStatus(featureName);
    }
}

// Response model
public class FeatureStatus {
    private String name;
    private boolean enabled;
    private String description;
    private Instant lastModified;
    
    // constructors, getters, setters
}
Creating Writable Endpoint

@Component
@Endpoint(id = "cache")
public class CacheManagementEndpoint {
    
    private final CacheManager cacheManager;
    
    public CacheManagementEndpoint(CacheManager cacheManager) {
        this.cacheManager = cacheManager;
    }
    
    @ReadOperation
    public Map cacheInfo() {
        Map info = new HashMap<>();
        info.put("caches", cacheManager.getCacheNames());
        info.put("timestamp", Instant.now());
        return info;
    }
    
    @WriteOperation
    public String clearCache(@Selector String cacheName) {
        Cache cache = cacheManager.getCache(cacheName);
        if (cache != null) {
            cache.clear();
            return "Cache '" + cacheName + "' cleared successfully";
        }
        return "Cache '" + cacheName + "' not found";
    }
    
    @WriteOperation
    public String clearAllCaches() {
        cacheManager.getCacheNames().forEach(name -> {
            Cache cache = cacheManager.getCache(name);
            if (cache != null) {
                cache.clear();
            }
        });
        return "All caches cleared successfully";
    }
    
    @DeleteOperation
    public String evictCacheEntry(@Selector String cacheName, String key) {
        Cache cache = cacheManager.getCache(cacheName);
        if (cache != null) {
            cache.evict(key);
            return "Key '" + key + "' evicted from cache '" + cacheName + "'";
        }
        return "Cache '" + cacheName + "' not found";
    }
}
Web-specific Endpoint

@Component
@WebEndpoint(id = "requests")
public class RequestMetricsEndpoint {
    
    private final MeterRegistry meterRegistry;
    
    public RequestMetricsEndpoint(MeterRegistry meterRegistry) {
        this.meterRegistry = meterRegistry;
    }
    
    @ReadOperation
    public Map requestMetrics() {
        Map metrics = new HashMap<>();
        
        // Get HTTP request metrics
        Counter counter = meterRegistry.find("http.server.requests").counter();
        if (counter != null) {
            metrics.put("totalRequests", counter.count());
        }
        
        Timer timer = meterRegistry.find("http.server.requests").timer();
        if (timer != null) {
            metrics.put("meanResponseTime", timer.mean());
            metrics.put("maxResponseTime", timer.max());
        }
        
        return metrics;
    }
    
    @ReadOperation
    public Object requestMetricsByStatus() {
        return meterRegistry.find("http.server.requests").counters().stream()
            .collect(Collectors.toMap(
                c -> c.getId().getTag("status"),
                Counter::count
            ));
    }
}

Spring Security Configuration

@Configuration
@EnableWebSecurity
public class ActuatorSecurityConfig {
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(authz -> authz
                // Public health and info endpoints
                .requestMatchers("/actuator/health").permitAll()
                .requestMatchers("/actuator/info").permitAll()
                .requestMatchers("/actuator/metrics").permitAll()
                
                // Sensitive endpoints require authentication
                .requestMatchers("/actuator/**").hasRole("ADMIN")
                
                // All other requests
                .anyRequest().authenticated()
            )
            .httpBasic(Customizer.withDefaults());
        
        return http.build();
    }
    
    // In-memory users for demonstration
    @Bean
    public InMemoryUserDetailsManager userDetailsService() {
        UserDetails user = User.withUsername("user")
            .password("{noop}password")
            .roles("USER")
            .build();
            
        UserDetails admin = User.withUsername("admin")
            .password("{noop}admin")
            .roles("USER", "ADMIN")
            .build();
            
        return new InMemoryUserDetailsManager(user, admin);
    }
}

// More advanced security configuration
@Configuration
public class AdvancedActuatorSecurity {
    
    @Bean
    @Order(1)
    public SecurityFilterChain actuatorSecurityFilterChain(HttpSecurity http) throws Exception {
        http
            .securityMatcher("/actuator/**")
            .authorizeHttpRequests(authz -> authz
                .requestMatchers("/actuator/health").permitAll()
                .requestMatchers("/actuator/info").permitAll()
                .requestMatchers("/actuator/metrics").hasRole("MONITORING")
                .requestMatchers("/actuator/**").hasRole("ADMIN")
            )
            .httpBasic(Customizer.withDefaults())
            .sessionManagement(session -> session.sessionCreationPolicy(SessionCreationPolicy.STATELESS));
        
        return http.build();
    }
}

Troubleshooting Common Issues

1. Endpoints Not Accessible

Problem: Actuator endpoints return 404.

Solutions:

  • Check if actuator dependency is included
  • Verify endpoint exposure configuration
  • Check if endpoint is enabled
  • Verify base path and port settings
2. Health Indicators Not Showing Details

# Enable health details
management.endpoint.health.show-details=always
# Or for specific roles
management.endpoint.health.show-details=when-authorized
3. Metrics Not Appearing in Prometheus

Check:

  • Prometheus registry dependency is included
  • Prometheus endpoint is exposed
  • Prometheus can reach your application
  • No firewall rules blocking access
4. Custom Endpoint Not Working

// - Endpoint not enabled in configuration

5. Security Configuration Blocking Access

@Configuration
public class SecurityConfig {
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(authz -> authz
                // Don't forget to permit actuator endpoints!
                .requestMatchers("/actuator/health").permitAll()
                .requestMatchers("/actuator/info").permitAll()
                .requestMatchers("/actuator/**").authenticated()
            );
        return http.build();
    }
}
