Step-by-Step Guide

1

Create Your Dockerfile

A Dockerfile is a text document that contains all the commands to build your Docker image.

# Use an official runtime as a base image
FROM node:18-alpine

# Set the working directory
WORKDIR /app

# Copy package files
COPY package*.json ./

# Install dependencies
RUN npm install

# Copy application code
COPY . .

# Expose the application port
EXPOSE 3000

# Define the command to run the app
CMD ["npm", "start"]
2

Build Your Docker Image

Build your image from the Dockerfile. The -t flag tags your image with a name.

docker build -t my-app .
3

Run Your Container

Start a container from your image. The -p flag maps container ports to host ports.

docker run -d -p 3000:3000 --name my-running-app my-app
4

Test Your Application

Access your application at http://localhost:3000 and verify it's working correctly.

# Check running containers docker ps # View container logs docker logs my-running-app # Test the application curl http://localhost:3000

Application Examples

Python Flask App

FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .

EXPOSE 5000

CMD ["python", "app.py"]

React Application

# Build stage
FROM node:18-alpine as build
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build

# Production stage
FROM nginx:alpine
COPY --from=build /app/build /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

Java Spring Boot

FROM openjdk:17-jdk-slim

VOLUME /tmp

COPY target/*.jar app.jar

EXPOSE 8080

ENTRYPOINT ["java","-jar","/app.jar"]

Static Website

FROM nginx:alpine

COPY . /usr/share/nginx/html

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]

Essential Docker Commands

Basic Commands

docker --version Check Docker version
docker images List all images
docker ps List running containers
docker ps -a List all containers

Management Commands

docker stop container_name Stop a container
docker rm container_name Remove a container
docker rmi image_name Remove an image
docker logs container_name View container logs

Quick Start Template

Use this template to quickly dockerize any Node.js application:

Dockerfile

FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["npm", "start"]

Build & Run:

docker build -t my-app .
docker run -p 3000:3000 my-app

.dockerignore

node_modules npm-debug.log .git .env
