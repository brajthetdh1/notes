3.4.2 Using the EC2 Dashboard

The EC2 Dashboard is your mission control center for managing all aspects of your virtual servers and related infrastructure in the cloud. It provides a comprehensive, at-a-glance view of your EC2 resources and serves as the primary entry point for performing management tasks.

Understanding the EC2 Dashboard Layout

When you select EC2 from the AWS Management Console or search for it, you are taken to the EC2 Dashboard. It is designed to give you a quick overview of your environment in the current AWS Region.

Key Sections of the Dashboard:
  • 📊 Resource Summary: A quick snapshot of your key EC2 resources in the current region.
  • ✅ Service Health: Status of EC2 services in the current region.
  • ⚡ Quick Launch Section: Quick access to launching an instance and other common actions.
  • 📋 Recent Events: Recent activity and events related to your EC2 resources.
  • 📂 Left Navigation Pane: The primary tool for drilling down into specific management tasks.

Performing Common EC2 Tasks

1. Launching a New EC2 Instance
  • Click Launch Instance from Quick Actions
  • Enter a name for your instance
  • Choose an AMI (Quick Start, Marketplace, or custom)
  • Choose an Instance Type (e.g., t3.micro, m5.large)
  • Create or select a Key Pair for SSH/RDP access
  • Configure Network Settings (VPC, subnet, security groups)
  • Configure Storage (root and additional EBS volumes)
  • Click Launch Instance

2. Connecting to an EC2 Instance
  • From the Instances page, select your instance
  • Click Connect at the top
  • Choose a connection method:
    • EC2 Instance Connect — Browser-based SSH (Linux)
    • Session Manager — Browser-based SSH via Systems Manager
    • SSH Client — Terminal + key pair
    • RDP Client — Connect to a Windows instance

3. Managing Instance State
  • From the Instances page, select one or more instances
  • Click the Instance State dropdown
  • Choose an action:
    • Start — Start a stopped instance (billing resumes)
    • Stop — Stop a running instance (billing stops for compute)
    • Reboot — Reboot the instance (preserves data)
    • Terminate — Permanently delete the instance (use with caution)

4. Creating an AMI from an Instance
  • From the Instances page, select a running instance
  • Click Actions → Image → Create Image
  • Enter a name and description
  • Click Create Image

Customizing the EC2 Dashboard Experience

Creating Custom Dashboards with CloudWatch
While the EC2 Dashboard provides a high-level overview, you can create custom CloudWatch dashboards for deeper monitoring:
  • Navigate to CloudWatch → Dashboards
  • Click Create Dashboard
  • Enter a name and click Create
  • Add widgets for metrics like:
    • CPU Utilization (average across instances)
    • Network In/Out
    • Disk Read/Write
    • Status Check Metrics (instance and system status)

Filtering and Sorting Instances
The Instances page supports powerful filtering and sorting:
  • Filter by State: Running, Stopped, Terminated, Pending
  • Filter by Tags: Use tag key-value pairs to show only specific resources
  • Filter by Search: Find instances by name, ID, IP, or other attributes
  • Sort by Columns: Click column headers to sort by any attribute

Adding and Removing Columns
  • Click the gear icon (⚙️) on the Instances page
  • Check or uncheck columns to add or remove them
  • Click Confirm to save your preferences

Review Questions

Q1: What information does the Resource Summary section of the EC2 Dashboard provide?
Answer: The Resource Summary provides a quick count of your key EC2 resources in the current region. This includes running and stopped instances, volumes, snapshots, AMIs, Elastic IPs, security groups, key pairs, load balancers, and Auto Scaling groups. Clicking on any resource type takes you directly to its detailed management page.
Q2: What Quick Actions are available from the EC2 Dashboard?
Answer: The Quick Actions section provides one-click access to common EC2 tasks, including:
  • Launch Instance — create a new EC2 instance
  • Create AMI — create an AMI from an instance
  • Create Volume — create a new EBS volume
  • Create Key Pair — create an SSH/RDP key pair
  • Create Security Group — create a new security group
  • Create Snapshot — create a snapshot of an EBS volume
Q3: Why is the Resource Summary considered region-specific?
Answer: The Resource Summary only shows resources that exist in the currently selected AWS Region (e.g., us-east-1). If you have resources deployed in multiple regions, you must change the region selector to view the counts for each region. This behavior is crucial for avoiding confusion when managing multi-region architectures.
Q4: What are the main categories in the EC2 left navigation pane?
Answer: The left navigation pane is organized into these main categories:
  • 🚀 Instances — EC2 instances, launch templates, Spot Requests
  • 💾 Images — AMIs and AMI Catalog
  • 📦 Storage — EBS volumes, snapshots, Lifecycle Manager
  • 🌐 Network & Security — Security Groups, Elastic IPs, Network ACLs
  • ⚖️ Load Balancing — Load Balancers and Target Groups
  • 💻 Auto Scaling — Auto Scaling Groups
  • 📊 Monitoring — CloudWatch Metrics and Alarms
Q5: How can you customize the Instances page to show only the information you need?
Answer: You can customize the Instances page by:
  • Adding/Removing Columns: Click the gear icon (⚙️) to add or remove columns from the Instances table.
  • Filtering by State or Tags: Use the filter bar to show only instances that meet specific criteria.
  • Sorting: Click column headers to sort by any attribute (e.g., click "Instance Type" to sort by instance type).
