4.3.1 Using the EC2 Console to Find an AMI

The EC2 console provides a user-friendly interface for discovering and selecting AMIs. There are two main paths: selecting an AMI during the instance launch process, or searching for an AMI through the dedicated AMI page. Both approaches are effective, and the choice depends on your workflow.

Path 1: The Launch Instance Wizard

Quick Start
The Launch Instance wizard is the most direct path if you're planning to launch an instance immediately. It guides you through all the required configuration steps, starting with the AMI selection.

1. Open the EC2 Console and Set Your Region
  • Sign in to the AWS Management Console and navigate to the EC2 service at https://console.aws.amazon.com/ec2/.
  • Select the AWS Region where you want to launch your instance. AMI IDs are unique to each Region.

2. Start the Launch Instance Wizard
  • From the EC2 Dashboard, click the Launch instance button.

3. Navigate the AMI Section
  • In the launch wizard, find the Application and OS Images (Amazon Machine Image) section.
  • You'll see several tabs to help you find the right image.

4. Using the Quick Start Tab
  • The Quick Start tab is the default view. It lists popular, commonly used AMIs organized by operating system.
  • Select the Free tier only checkbox to filter for AMIs eligible for the AWS Free Tier.

  • Use the Search bar to find AMIs by keyword (e.g., "Ubuntu" or "Nginx").
  • When you find an AMI, choose Select to use it for your instance launch.

Path 2: The AMI Page

Dedicated Search
For more advanced searching or for finding an AMI to use in a future launch, the dedicated AMI page provides more granular filtering and search capabilities.

1. Open the AMI Page
  • In the EC2 console, from the navigation pane, choose AMI.

2. Set Your Region
  • Ensure the correct Region is selected. AMI IDs are unique to each Region.

3. Use the Initial Filter
  • Public images: Shows AMIs that are publicly accessible.
  • Private images: Shows AMIs that are shared with you privately.

4. Refine Your Search with Filters
  • Use the Search bar to apply specific filters.
  • Example: To view only AWS-provided AMIs, select Owner alias → = → amazon.
  • Example: To filter by OS, select Platform → = → windows or linux.

5. Customize the Display
  • Click the Preferences (gear) icon to add or remove columns.
  • Useful columns: Root device type (EBS-backed vs instance store-backed) and Virtualization type.

6. Review AMI Details
  • Click on any AMI to view its properties in the Details tab.
  • Critical information: Root device type, Architecture, and Owner.

Key Considerations When Selecting an AMI

  • 🌍 Region:
    The AMI must exist in the same Region where you plan to launch the instance.

  • 💾 Root Device Type:
    For most use cases, EBS-backed AMIs are preferred. They allow you to stop and start the instance without losing data on the root volume.

  • 🔒 Trusted Source:
    For production environments, always prefer AMIs from trusted sources.

  • ✅ Verified Provider:
    In the Community AMIs tab, look for the Verified provider label. This indicates the AMI is from Amazon or a verified partner.

  • ☁️ AWS-Provided:
    Use the filter Owner alias = amazon to find official AWS AMIs.

Key Takeaways

  • The EC2 console offers two main paths to find an AMI: the Launch Instance wizard and the dedicated AMI page.

  • The Quick Start tab in the Launch Instance wizard lists popular, commonly used AMIs.

  • The AMI page provides advanced filtering capabilities for more precise searches.

  • Community AMIs are not verified by AWS — use caution.

  • Always select an AMI from the same Region where you plan to launch your instance.

  • For production workloads, prefer EBS-backed AMIs from trusted providers (Owner alias = amazon or aws-marketplace).

  • Use the Details tab to review critical AMI properties like Root device type, Architecture, and Owner.

Review Questions

Q1: What are the two main paths to find an AMI in the EC2 console?
Answer: The two main paths are:
  • Path 1: The Launch Instance wizard — best for immediate instance launches.
  • Path 2: The dedicated AMI page — best for advanced searching and future launches.
Q2: What tabs are available in the "Application and OS Images" section of the Launch Instance wizard?
Answer: The tabs are:
  • Quick Start — popular, commonly used AMIs
  • My AMIs — private AMIs you own or shared with you
  • AWS Marketplace — third-party AMIs with commercial software
  • Community AMIs — public AMIs shared by other users (not verified by AWS)
Q3: How can you filter the AMI list to show only AWS-provided AMIs in the AMI page?
Answer: In the AMI page search bar, select Owner alias, choose the = operator, and enter amazon as the value. This will filter the list to show only AMIs provided by AWS.
Q4: Why is it important to check the AMI's root device type before selecting it?
Answer: The root device type determines whether the root volume is persistent (EBS-backed) or ephemeral (instance store-backed). EBS-backed AMIs allow you to stop and start the instance without losing data on the root volume, which is critical for production workloads.
Q5: What should you look for in the Community AMIs tab to ensure you are using a trusted AMI?
Answer: Look for the Verified provider label. This indicates that the AMI is from Amazon or a verified partner, providing a higher level of trust and security.
