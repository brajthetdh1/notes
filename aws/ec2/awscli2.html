3.3.1 Installing AWS CLI on Windows, macOS, and Linux

The AWS Command Line Interface (AWS CLI) is a powerful tool that enables you to interact with AWS services directly from your terminal. This section covers installing the current AWS CLI version 2 on all major operating systems — Windows, macOS, and Linux.

⚠️ Version 1 is effectively deprecated and you should always use version 2 for the latest features and security updates.
💻 AWS CLI v2 🪟 Windows 🍎 macOS 🐧 Linux
📦

Why AWS CLI Version 2?

Before we dive into installation, it's important to understand why version 2 is the recommended choice:

📦 Standalone Installation
Unlike version 1 (installed via pip), version 2 is a standalone application. Not designed for Python virtual environments.
⚡ Better Performance
Version 2 is faster and more efficient than version 1.
🚀 Enhanced Features
New features like aws sso login are available only in version 2.
🔮 Future-Proof
AWS continues to develop version 2, while version 1 is effectively deprecated.
📦 v2 benefits ⚡ performance 🚀 features
🪟

Installing on Windows

The simplest and most reliable method for installing the AWS CLI on Windows is using the official MSI installer.

Interactive Installation (Recommended for Beginners):
  1. Download the MSI installer from: https://awscli.amazonaws.com/AWSCLIV2.msi
  2. Double-click the downloaded .msi file and follow the installation wizard.
  3. Accept the license terms, choose the installation location, and click Install.
  4. Handle any User Account Control (UAC) prompts that may appear.

Silent Installation (For Automation):
msiexec.exe /i https://awscli.amazonaws.com/AWSCLIV2.msi /qn
💡 The /qn flag performs a completely silent installation with no user interface.

Verification:
aws --version
Expected Output Example:
aws-cli/2.27.50 Python/3.10.6 Windows/10 exe/AMD64
🪟 Windows 📦 MSI 🤫 silent install
🍎

Installing on macOS

There are two primary methods to install the AWS CLI on macOS.

Method 1: Official .pkg Installer (Recommended)
# Download the package curl "https://awscli.amazonaws.com/AWSCLIV2.pkg" -o "AWSCLIV2.pkg" # Run the installer sudo installer -pkg AWSCLIV2.pkg -target /
📂 Installation Details: Files are installed to /usr/local/aws-cli, and a symlink is automatically created in /usr/local/bin. You must include sudo to grant write permissions.

Method 2: Homebrew (Alternative for Homebrew Users)
brew install awscli

Verification:
which aws
Expected Output:
/usr/local/bin/aws
aws --version
Expected Output Example:
aws-cli/2.9.23 Python/3.9.11 Darwin/21.6.0 exe/x86_64
🍎 macOS 📦 .pkg 🍺 Homebrew
🐧

Installing on Linux

The installation process on Linux involves downloading a zip file and running the installer.

Prerequisites:
# For Debian/Ubuntu sudo apt update && sudo apt install unzip -y # For Amazon Linux/RHEL/CentOS sudo yum install unzip -y
⚠️ Important: If you are on Amazon Linux, you may need to first remove the pre-installed yum version of AWS CLI before installing version 2:
sudo yum remove awscli

Installation Steps:
# For x86_64 (standard 64-bit) systems curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip" # For ARM/aarch64 systems (including AWS Graviton) curl "https://awscli.amazonaws.com/awscli-exe-linux-aarch64.zip" -o "awscliv2.zip" # Unzip and install unzip awscliv2.zip sudo ./aws/install

Alternative: Installing as a Snap on Ubuntu
sudo snap install aws-cli --classic

Verification:
aws --version
Expected Output Example:
aws-cli/2.27.50 Python/3.10.6 Linux/5.15.0-1030-aws exe/x86_64
🐧 Linux 📦 zip 🔄 snap 🦾 Graviton

Troubleshooting "Command Not Found"

If you receive a command not found error after installation, the AWS CLI may not be in your system's PATH.

🍎 macOS / 🐧 Linux
Check that /usr/local/bin is in your $PATH. Run echo $PATH and look for /usr/local/bin. If missing, add it to your shell's profile file (e.g., .zshrc or .bashrc).
🪟 Windows
Ensure the installation directory (typically C:\Program Files\Amazon\AWSCLIV2\) is in your PATH. You may need to restart your terminal or computer after installation.

💡 Quick Tip: Always open a new terminal after installing the AWS CLI before testing the aws --version command.

Review Questions

Q1: Why is AWS CLI version 2 recommended over version 1?
Answer: AWS CLI version 2 is the current, actively developed version. Version 1 is effectively deprecated and missing features you'll want, such as improved performance and support for aws sso login. AWS CLI v2 is not typically installed via pip; it's installed as a standalone application for better compatibility and performance.
Q2: What are the two ways to install AWS CLI on macOS?
Answer: The recommended method is to download the official .pkg installer from AWS using curl, then run sudo installer -pkg AWSCLIV2.pkg -target /. Alternatively, if you use Homebrew, you can install it with brew install awscli.
Q3: Which Linux installation package should you download for a Graviton (ARM-based) EC2 instance?
Answer: For ARM/aarch64 systems like AWS Graviton instances, you should download the architecture-specific package using curl "https://awscli.amazonaws.com/awscli-exe-linux-aarch64.zip" -o "awscliv2.zip". For standard x86_64 systems, use awscli-exe-linux-x86_64.zip.
Q4: What prerequisite must be installed before running the AWS CLI Linux installer?
Answer: You must have unzip installed to extract the downloaded zip file. You can install it using sudo apt install unzip -y (Debian/Ubuntu) or sudo yum install unzip -y (Amazon Linux/RHEL/CentOS). Additionally, on Amazon Linux, you may need to remove the pre-installed yum version of AWS CLI with sudo yum remove awscli before installing version 2.
Q5: How can you verify that the AWS CLI was installed correctly?
Answer: Open a new terminal (or Command Prompt/PowerShell on Windows) and run the command aws --version. If the installation was successful, you will see output showing the version of the AWS CLI, Python, and your operating system platform (e.g., aws-cli/2.27.50 Python/3.10.6 Windows/10 exe/AMD64).
