3Sum — Solution & Walkthrough

🧠 Approach: Sort + Two Pointers

  1. Sort the array — duplicates become adjacent, and two-pointer technique becomes possible.
  2. Fix index i (the smallest of the triplet).
    • Skip duplicate i values.
    • Set target = -nums[i], then find a pair (left, right) in the remaining subarray that sums to target.
  3. Move pointers based on sum:
    • sum == target → record triplet, advance left & retreat right (skipping dups)
    • sum < target → left++
    • sum > target → right--
  4. Early exit: if nums[i] > 0 (after sorting), break — all remaining numbers are positive, so no triplet can sum to zero.

Brute Force (3 loops)O(n³)O(1)
Sort + Two Pointers ✅O(n²)O(1)*

💻 Full Solution (Java)

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class Main {

    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        if (nums == null || nums.length < 3) return result;

        // 1) Sort so duplicates are adjacent and two-pointer works
        Arrays.sort(nums);
        int n = nums.length;

        // 2) Fix the first element of the triplet
        for (int i = 0; i < n - 2; i++) {
            // Early exit: once nums[i] > 0, no triplet can sum to 0
            if (nums[i] > 0) break;

            // Skip duplicate i values
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            int left = i + 1;
            int right = n - 1;
            int target = -nums[i];

            // 3) Two-pointer search for the remaining pair
            while (left < right) {
                int sum = nums[left] + nums[right];

                if (sum == target) {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));

                    // Skip duplicate left values
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    // Skip duplicate right values
                    while (left < right && nums[right] == nums[right - 1]) right--;

                    // Move both inward to continue search
                    left++;
                    right--;
                } else if (sum < target) {
                    left++;
                } else {
                    right--;
                }
            }
        }

        return result;
    }

    // =====================================================================
    // TEST CASES
    // =====================================================================
    public static void main(String[] args) {
        Main solution = new Main();

        runTest(solution, new int[]{-1, 0, 1, 2, -1, -4},
                List.of(List.of(-1, -1, 2), List.of(-1, 0, 1)));

        runTest(solution, new int[]{0, 1, 1}, List.of());

        runTest(solution, new int[]{0, 0, 0},
                List.of(List.of(0, 0, 0)));

        runTest(solution, new int[]{1, 2, 3, 4}, List.of());

        runTest(solution, new int[]{-1, -2, -3, -4}, List.of());

        runTest(solution, new int[]{-2, 0, 0, 2, 2},
                List.of(List.of(-2, 0, 2)));

        runTest(solution,
                new int[]{-4,-2,-2,-2,0,1,2,2,2,3,3,4,4,6,6},
                List.of(
                        List.of(-4, -2, 6),
                        List.of(-4, 0, 4),
                        List.of(-4, 1, 3),
                        List.of(-4, 2, 2),
                        List.of(-2, -2, 4),
                        List.of(-2, 0, 2)
                ));

        runTest(solution, new int[]{-1, 0, 1},
                List.of(List.of(-1, 0, 1)));

        runTest(solution, new int[]{-2, -2, -2, 4, 4, 4},
                List.of(List.of(-2, -2, 4)));

        runTest(solution, new int[]{0, 0, 0, 0},
                List.of(List.of(0, 0, 0)));

        runTest(solution, new int[]{-3, 1, 2},
                List.of(List.of(-3, 1, 2)));

        runTest(solution, new int[]{-3, 1, 3}, List.of());
    }

    // =====================================================================
    // TEST HELPERS
    // =====================================================================
    private static void runTest(Main solution, int[] nums, List<List<Integer>> expected) {
        List<List<Integer>> result = solution.threeSum(nums);

        List<List<Integer>> normResult   = normalize(result);
        List<List<Integer>> normExpected = normalize(expected);
        boolean passed = normResult.equals(normExpected);

        System.out.printf("Input: nums=%s%n", Arrays.toString(nums));
        System.out.printf("Expected: %s%n", normExpected);
        System.out.printf("Got     : %s%n", normResult);
        System.out.printf("Result  : %s%n%n", passed ? "✅ PASS" : "❌ FAIL");
    }

    private static List<List<Integer>> normalize(List<List<Integer>> input) {
        List<List<Integer>> out = new ArrayList<>();
        if (input == null) return out;
        for (List<Integer> t : input) {
            List<Integer> sorted = new ArrayList<>(t);
            sorted.sort(Integer::compareTo);
            out.add(sorted);
        }
        out.sort((a, b) -> {
            for (int i = 0; i < Math.min(a.size(), b.size()); i++) {
                int c = Integer.compare(a.get(i), b.get(i));
                if (c != 0) return c;
            }
            return Integer.compare(a.size(), b.size());
        });
        return out;
    }
}

🛡️ The 4 Critical Guards

Each of these lines is essential — remove any one and you get either duplicate triplets or wrong answers:

if (nums[i] > 0) break;                          // 1. Early exit
if (i > 0 && nums[i] == nums[i - 1]) continue;   // 2. Dedup i
while (left < right && nums[left] == nums[left + 1]) left++;      // 3. Dedup left
while (left < right && nums[right] == nums[right - 1]) right--;    // 4. Dedup right
⚠️ Why left < right inside guards 3 & 4?

Without it, edge cases like [0, 0, 0] would throw ArrayIndexOutOfBoundsException when left runs off the end (or right runs below zero). The bound check keeps the loop safe.

TimeO(n²)Outer loop n iterations × inner two-pointer n steps

🔁 Alternative Approach: HashSet (slower, messier)

You can fix i and use a HashSet for the inner Two Sum. It's still O(n²) time but uses O(n) extra space and requires a Set<List<Integer>> for deduplication, which is messier.

The sort + two-pointer version is the standard interview answer — memorize it.
