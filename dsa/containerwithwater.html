Problem 2: Container With Most Water

Medium LeetCode #11 Two Pointers Array Greedy

📖 Question

You are given an integer array height of length n. There are n vertical lines drawn such that the two endpoints of the i-th line are (i, 0) and (i, height[i]).

Find two lines that together with the x-axis form a container, such that the container contains the most water.

Return the maximum amount of water a container can store.

Notice that you may not slant the container.

Visual Example

Constraints

  • n == height.length
  • 2 ≤ n ≤ 10⁵
  • 0 ≤ height[i] ≤ 10⁴

💡 Key Insight

The water trapped between lines i and j is: 

area = min(height[i], height[j]) × (j - i)
                 ↑                      ↑
             shorter line             width

Start with the widest container (leftmost + rightmost). Then move the pointer pointing to the shorter line inward. Since the width only shrinks each step, the only way to beat the current best is to find a taller line — which is exactly what moving the shorter pointer might reveal.

Why not move the taller one?
If you move the taller pointer inward, the width shrinks and the height is capped by the still-shorter other line → area can only decrease. Moving the shorter pointer is the only move that has any chance to increase the area.

🎯 Approach Guidance

Brute Force (O(n²)) — start here to understand the problem

Try every pair of lines (i, j) with i < j:

int best = 0;
for (int i = 0; i < height.length; i++) {
    for (int j = i + 1; j < height.length; j++) {
        int area = Math.min(height[i], height[j]) * (j - i);
        best = Math.max(best, area);
    }
}
return best;

Correct, but too slow — LeetCode will TLE at n = 10⁵.

Optimal Two-Pointer (O(n)) — the interview answer
  1. Set left = 0, right = n − 1, best = 0.
  2. While left < right:
    • Compute area = min(height[left], height[right]) × (right − left).
    • Update best.
    • Move the pointer pointing to the shorter line inward:
      • If height[left] < height[right] → left++.
      • Else → right--.
  3. Return best.

Time: O(n) — each pointer moves at most n steps.
Space: O(1) — only two pointers and a best-so-far variable.

💡 Sanity check: with the example [1,8,6,2,5,4,8,3,7], the two-pointer walk should output 49 in linear time.
